
# 数据集

UAVDT
# 模型架构配置

骨干网络：videomamba-T1
- 预训练权重：videomamba_t16_k400_f8_res224.pth
检测头：DINO
- 预训练权重：eckpoint0033_4scale.pth

关键参数：
- 输入尺寸：512×896
- 视频帧数：16帧
- 隐藏层维度：256
- 编码/解码层数：各6层
- 注意力头数：8
- 特征金字塔层数：4
- 检测查询数：300

训练配置：
- Epoch：12个epoch
- **Batch_size**：2
- **学习率**：0.0001
- **学习率调整**：
    - 第8、11个epoch时下降10倍
- **损失函数权重**：
    - 分类损失：2.0
    - 边界框损失：5.0
    - GIoU损失：2.0
- **数据增强**：
    - 去噪训练（DN）：100个噪声查询
    - 噪声比例：标签噪声0.5，边界框噪声0.4
