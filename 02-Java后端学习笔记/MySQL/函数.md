
- 字符串函数
```mysql
# 字符串拼接
concat(S1,S2,...Sn) 
# 将字符串全部转为小写
lower(str)
# 全部转为大写
upper(str)
# 左填充，用字符串pad对str的左边进行填充，达到n个字符串长度
lpad(str,n,pad)
# 右填充，用字符串pad对str的右边进行填充，达到n个字符串长度
rpad(str,n,pad)
# 去掉字符串头部和尾部的空格
trmi(str)
# 返回字符串str从start位置起的len个长度的字符串
substring(str,start,len)
```
- 数值函数
```mysql
# 向上取整
ceil(x)
# 向下取整
floor(x) 
# 返回x/y的模
mod(x,y)
# 返回0~1内的随机数
rand()
# 求参数x的四舍五入的值，保留y位小数
round(x,y)
```
- 日期函数
```mysql
curdate() # 返回当前日期
curtime() # 返回当前时间
now()     # 返回当前日期和时间
year(data) #获取指定date的年份
month(data) # 获取指定data的月份
day(date) # 获取指定date的日期
date_add(date,interval expr type) #返回一个日期/时间值加上一个时间间隔expr后的时间值
datediff(date1,date2) # 返回起始时间date1到结束时间date2之间的天数
```
- 流程控制函数
```mysql
# 如果value为true,则返回t,否则返回f
if(value,t,f)
# 如果value不为null,则返回value1，否则返回value2
ifnull(value1,value2)
# 如果val1为true,返回res1,...否则返回default1默认值
case when val1 then res1.....else default end
```
