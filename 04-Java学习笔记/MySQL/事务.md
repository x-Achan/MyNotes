
> 事务是一组操作的集合，它是一个不可分割的工作单位，事务会把所有操作作为一个整体一起向系统给提交或者撤销操作请求，**即这些操作要么同时成功，要么同时失败**

1. 事务操作

- 方式1

查看/设置事务提交方式
```mysql
select @@autocommit;
set @@autocommit=0; # 0代表自动提交 1代表手动提交
```
- 方式2
开启事务
```mysql
start transaction 或 begin
```
提交事务
```mysql
commit
```
回滚事务
```mysql
rollback
```


2. 事务四大特性：
- 原子性：操作不可分割
- 一致性：数据保持正确状态
- 隔离性：多个事务同时执行时，互相不要产生错误影响
	- 脏读：一个事务读取到了另一个事务未提交的数据
	- 不可重复读：同一个事务里面，两次查询同一条记录，结果不同
	- 幻读：查询结果行数增加或减少，同一事务两次查询出现不同数量的数据
- 持久性：提交后永久保存

3. 事务隔离级别：
Read uncommitted：脏读、不可重复读、幻读
Read conmmitted：不可重复读、幻读
Repeatable Read(默认)：幻读
Serializable：

事务隔离级别越高，数据越安全，但是性能越低
查看事务隔离级别：
```mysql
select @@transaction_isolation
```
设置事务隔离级别
```mysql
# session只对当前会话 global对全局
set [session|global] transaction isolation level [事务隔离级别] 
```
