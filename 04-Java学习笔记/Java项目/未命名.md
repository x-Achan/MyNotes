
**项目分层结构：**

```
- common
	- Result.java：把任何类型的数据（T），统一打包成 Result 的格式返回
- controller
	- UserController.java：接收HTTP请求，调用Service，返回结果
- dto
	- UserCreateRequest.java：接收前端传来的新增用户请求
- entity
	- User.java：承载数据库中的完整数据
- repository
	- UserRepository.java：负责访问数据库，写SQL，执行SQL，把数据库结果转成Java对象
- service
	- UserService.java：负责业务逻辑，调用 Repository 查询数据库，将 User 转成 UserVO
- vo
	- UserVO.java：前端展示的数据，不包含敏感字段
```


为什么建立 DTO / Entity / VO 三种 User 形式？

```
不同对象服务于不同场景，避免前端接触到数据库完整结构，也避免泄露敏感字段。
```



**一次 GET 请求过程**

```java
GET http://localhost:8081/api/users
```

完整的流程是：
1. 浏览器发送GET请求到 localhost:8081/api/users
2. Spring Boot 内置的 Tomcat 接收到请求
3. Spring 根据路径找到了 UserController.listUsers()
4. 执行 Service 业务逻辑和 Repository 数据库操作
5. MySQL 返回业务表里的数据
6. Repository 把数据库行转换成 User 对象
7. Service 把 User 对象转换为 UserVO 对象
8. Controller 用 Result.success 包装
9. Spring 把 Java 对象转换为 Json
10. 浏览器显示 Json

**一次 POST 请求的过程（在终端输入）**

```java
$body = @{
  username = "test03"
  password = "123456"
  nickname = "test user 03"
  email = "test03@example.com"
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://localhost:8081/api/users" -Method Post -ContentType "application/json" -Body $body
```

1. PowerShell 发送 POST 请求
2. Spring Boot 接收到请求
3. 根据 POST 路径 api/users 找到 UserController.createUser()
4. @RequestBody 把 json 转成 UserCreateRequest
5. Controller 调用 UserService.createUser(request) 
6. Service 创建 User 对象
7. Repository 执行 INSERT SQL
8. MySQL 插入新用户
9. Controller 返回 Result.success()
10. 客户端看到 code=200，message=success


**Result.java 中的代码解析**

```java
public static <T> Result<T> success(T data) {  
    return new Result<>(200, "success", data);  
}
```


泛型声明 `<T>`
- 泛型类：修饰符 class 类名`<T>`，public class Result`<T>`
- 泛型方法：修饰符 `<T>` 返回值类型 方法名，public `<T>` Result`<T>` success(...)

类的泛型，是跟着对象走的，只有当你 new 一个对象的时候，类的泛型才会确定。但是对于 static 静态方法来说，方法是属于类的，可以通过类名调用，所以根本不需要 new 一个对象，所以静态方法无法感知泛型类中的 `<T>`，必须自己声明一个属于自己的`<T>`



**UserRepository 的 findAll() 解析：**

```java
public List<User> findAll() {  
    String sql = """  
		SELECT id, username, password, nickname, email, role, status,                      create_time, update_time, is_deleted            
		FROM `user`            
		WHERE is_deleted = 0            
		ORDER BY id DESC            
		""";  
  
    return jdbcTemplate.query(sql, (rs, rowNum) -> {  
        User user = new User();  
        user.setId(rs.getLong("id"));  
        user.setUsername(rs.getString("username"));  
        user.setPassword(rs.getString("password"));  
        user.setNickname(rs.getString("nickname"));  
        user.setEmail(rs.getString("email"));  
        user.setRole(rs.getString("role"));  
        user.setStatus(rs.getInt("status"));  
        user.setCreateTime(rs.getTimestamp("create_time").toLocalDateTime());  
        user.setUpdateTime(rs.getTimestamp("update_time").toLocalDateTime());  
        user.setIsDeleted(rs.getInt("is_deleted"));  
        return user;  
    });  
}
```

执行 jdbcTemplate.query 先向数据库执行一次 sql 语句，获取到所有数据的总结果集，然后jdbcTemplate 在内存中逐行遍历 rs，将当前行的 rs 和行号 rowNum 交给你，对每一行数据执行一次 Lambda 表达式的内容，进行数据打包操作，每一行返回一个 user

最后 jdbcTemplate.query 会返回一个 List

**UserRepository 的 findById() 解析：**

```java
public User findById(Long id) {  
    String sql = """  
		SELECT id, username, password, nickname, email, role, status,                      create_time, update_time, is_deleted        
        FROM `user`        
        WHERE id = ? AND is_deleted = 0        
        """;  
  
    List<User> users = jdbcTemplate.query(sql, (rs, rowNum) -> {  
        User user = new User();  
        user.setId(rs.getLong("id"));  
        user.setUsername(rs.getString("username"));  
        user.setPassword(rs.getString("password"));  
        user.setNickname(rs.getString("nickname"));  
        user.setEmail(rs.getString("email"));  
        user.setRole(rs.getString("role"));  
        user.setStatus(rs.getInt("status"));  
        user.setCreateTime(rs.getTimestamp("create_time").toLocalDateTime());  
        user.setUpdateTime(rs.getTimestamp("update_time").toLocalDateTime());  
        user.setIsDeleted(rs.getInt("is_deleted"));  
        return user;  
    }, id);  
  
    return users.isEmpty() ? null : users.get(0);  
}
```

最后 jdbcTemplate.query 会返回一个 List，只取 List 第一个元素
