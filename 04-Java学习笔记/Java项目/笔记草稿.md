

**Spring boot 启动流程：**

1. 入口启动：从main方法的SpringApplication.run()方法开始执行
2. 加载配置环境：读取.yaml其中的参数，加载到内存中
3. 扫描组件与装配：启动类上的@SpringBootApplication注解会扫描当前包下的所有代码，发现@RestController和@Service等注解，将它们实例化，并且装进Spring 的IOC Container容器中统一管理
4. 启动内置Web服务器：Spring Boot发现依赖中有spring-boot-starter-web，则唤醒内置的Tomcat服务器，并将其绑定到配置文件的指定端口上（默认8080）
5. 服务就绪：控制台打印输出，接口可以接口外部访问
