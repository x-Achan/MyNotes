# LeetCode 49. 字母异位词分组

-----

**分组思想：找到数据之间的相同点，将具有相同特征的数据存储在一次，Key是特征，V是原始数据**

**利用哈希表对“具有相同特征”的数据进行分组，对于字母异位词，他们的特征可以通过“排序”或“记频”来提取**
- 排序：所有排序后相同的字符串，分为一组，用HashMap存储，key是排序后的字符串，value是字符串列表，最后通过map.value()取出所有分组。
- 记频：每个字母出现频次相同的字符串，分为一组
------

常用API总结：
1. 字符串转数组 + 排序

```java
char[] chars = str.toCharString(); // 将字符串转为char[] 类型数组
  
Arrays.sort(chars);  //数组排序，没有返回值
```

2. 获取Map中的value，并转为数组
```java
return new ArrayList<List<String>>(map.values());
```

- map.values()：返回所有value的集合（Collection）
- new ArrayList<>(map.values())：使用集合构造器创建对象

3. 使用getOrDefault简化逻辑
```java
List<String> group = map.getOrDefault(key, new ArrayList<>());
```
如果key存在，则取出value，如果key不存在，自动创建空list
