# ==LeetCode 42. 接雨水==

## 解法1：暴力遍历

每个格子所能容纳的水量，通过 leftmax 和 rightmax 的最小值决定的
每个格子的 leftmax 和 rightmax 都是通过遍历可以固定确定的，计算公式也是固定的
用两个数组，将固定的值都保存到数组中，最后统一计算

**在while循环中，要判断while( l <= i)，不能省略 = 号，如果自己比左边的所有板子都要高，则这个格子不能容纳水**

```java
class Solution {
    public int trap(int[] height) {
        int[] leftmax = new int[height.length];
        int[] rightmax = new int[height.length];
        int sums = 0;
        for(int i = 0; i < height.length;i++){
            int l = 0;
            int r = height.length - 1;
            while(l <= i){
                leftmax[i] = Math.max(height[l],leftmax[i]);  
                l++;        
            }
            while(r >= i){
                rightmax[i] = Math.max(height[r],rightmax[i]);
                r--;
            }
        }
        for(int j = 0;j < height.length;j++){
                sums += Math.min(leftmax[j],rightmax[j]) - height[j];
            }
        return sums;
    }
}
```

## 解法2：双指针解法：

left 指针和 right 指针，从两头往中间走，直到 left == right 会和，遍历完所有元素
leftmax 和 rightmax 的大小关系，用来判断处理 left 还是 right一边的元素，轮流判断，直到会和


left 向右移动 left++，==每次都会判断 height[left] 和 leftmax的大小：==
- 若 <= ：可以存储雨水，将 left 当前所在的单元格的雨水加到 sums 中
- 若 > : 说明不能存储水，更新 leftmax == height[left]

==每次操作，要么添加水量，要么更新leftmax==
操作完，继续移动left，left++

```java
class Solution {

    public int trap(int[] height) {
        int sums = 0;
        int l = 0;
        int r = height.length - 1;
        int lm = 0;
        int rm = 0;


        while( l <= r){
            if(height[l] <= height[r]){
                if(height[l] <= lm){
                    sums += lm - height[l];
                }else{
                    lm = height[l];        
                }
                l++;
            }else{
                if(height[r] <= rm){
                    sums += rm - height[r];
                }else{
                    rm = height[r];
                }
                r--;
            }
        }
        return sums;
    }
}
```
