
# ==LeetCode 46.全排列==

回溯的本质：
>尝试一条路，走到底后撤销之前的操作，恢复到历史状态，再尝试另一条路

回溯 = DFS + 状态恢复

使用状态数组，记录走过的路径

```java
class Solution {

    List<List<Integer>> ans = new ArrayList();
    List<Integer> path = new ArrayList();

    public List<List<Integer>> permute(int[] nums) {
        boolean[] flag = new boolean[nums.length];
        dfs(nums,flag);
        return ans;
    }

    public void dfs(int[] nums,boolean[] flag){
        if(path.size() == nums.length){
            ans.add(new ArrayList(path));
            return;
        }

        for(int i=0;i<nums.length;i++){
            if(flag[i] == true){
                continue;
            }

            path.add(nums[i]);
            flag[i] = true;
            
            dfs(nums,flag);
            
            path.remove(path.size()-1);
            flag[i] = false;
        }
    }
}
```


# ==**LeetCode 78.子集**==

```java
class Solution {
    List<List<Integer>> ans = new ArrayList<>();
    List<Integer> set = new ArrayList<>();

  
    public List<List<Integer>> subsets(int[] nums) {
        dfs(0,nums);
        return ans;
    }

    public void dfs(int begin,int[] nums){
        ans.add(new ArrayList<>(set));
        for(int i = begin;i<nums.length;i++){

            set.add(nums[i]);

            dfs(i+1,nums);

            set.remove(set.size()-1);
        }
    }
}
```


# LeetCode 17. 电话号码的字母组合

数字 到 字母的映射
每一层选择一个，传递index记录当前第几层

```java
class Solution {

    String[] map = {"","","abc","def","ghi","jkl","mno","pqrs","tuv","wxyz"};
    List<String> ans = new ArrayList<>();
    StringBuilder path = new StringBuilder();

    public List<String> letterCombinations(String digits) {

        dfs(0,digits);
        return ans;

    }
    public void dfs(int index,String digits){

        if(index == digits.length()){
            ans.add(path.toString());
            return;
        }

        char digit = digits.charAt(index);
        String letters = map[digit - '0'];

        for(char c : letters.toCharArray()){
            path.append(c);
            dfs(index + 1,digits);
            path.deleteCharAt(path.length() - 1);
        }       
    }
```



# LeetCode 39. 组合总和

对比 78题集合
相同点在于都用begin控制选择范围

>组合总和是子集模型的变形。相比子集，区别在于元素可以重复选择，因此递归时不是传 i+1，而是传 i；相比全排列，不需要 used，因为组合不关注顺序，只需要 begin 保证搜索方向，避免产生重复组合。

```
例子：[2,3,4,7]

78题集合：
第一次：2 3 4 7都可以选,选2
第二次: 3 4 7 ，传 begin + 1
(外层递归循环begin + 1，要将外层的begin传递下去，内层循环在外层begin的基础上还要 + 1)

39题组合
第一次：2 3 4 7，选 2
第二次： 2 3 4 7 都可以选，所以传begin
...
...
(当包含2的组合选完后)
外层递归循环 begin + 1，内存递归的循环不在外层递归的begin值上继续 +1
```

>核心:`begin` 控制的是“能不能回头选择”，而 `dfs(i)` 或 `dfs(i+1)` 决定的是“当前元素是否还能继续使用”。你现在对这个区别的理解已经接近回溯模板的核心了


```java
class Solution {
    List<List<Integer>> ans = new ArrayList<>();
    List<Integer> path = new ArrayList<>();
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        dfs(0,0,candidates,target);
        return ans;
    }

    public void dfs(int begin,int curSum,int[] candidates,int target){
        if(curSum == target){
            ans.add(new ArrayList(path));
            return;
        }
        if(curSum > target) return;
        
        for(int i = begin; i < candidates.length;i++){
        
            path.add(candidates[i]);
            curSum += candidates[i];
            
            dfs(i,curSum,candidates,target);
            
            curSum -= candidates[i];
            path.remove(path.size() - 1);
        }
    }
}
```
