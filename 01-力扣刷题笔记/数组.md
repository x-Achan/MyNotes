
# LeetCode 53. 最大子数组和

Kadane 算法，是在O(n)的时间复杂度和O(1)的空间复杂度，解决连续子数组最大和的方法
- 核心思想：利用以前算出来的结果来解决现在的问题
- 定义状态，用dp[i]，表示以i结尾的子数组最大和


负数舍断离：判断前面的和是否是负值（累赘）
贪心式的局部决策：
- 走到第 `i` 个数字时，我有两个选择：
    1. **接着前面的走**：`current_max + nums[i]`
    2. **前面是累赘，我自己重新开始**：`nums[i]`
- 选两者中较大的作为新的 `current_max`。
- 然后用它去挑战 `global_max` 的纪录。

# LeetCode 238. 除了自身以外数组的乘积
> 算法思想和接雨水类似
> 核心逻辑：当前位置的结果，都是“左信息” + “右信息”共同决定：

- **238题（数组乘积）：** `ans[i] = 左侧所有元素的乘积 * 右侧所有元素的乘积`
- **42题（接雨水）：** `water[i] = min(左侧最高柱子, 右侧最高柱子) - 当前柱子高度`


#### 解法1：前缀和

**==存储所有历史状态

提前遍历一遍数组，将每个元素左右两侧的前缀乘积保存到数组中，用L[]和R[]保存
时间复杂度O(n)，空间复杂度O(n)
```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int[] L = new int[nums.length];
        int[] R = new int[nums.length];
        int[] ans = new int[nums.length];
        L[0] = 1;
        R[nums.length-1] = 1;
  
        for(int i=1;i<nums.length;i++){
            L[i] = L[i-1]*nums[i-1];
            R[nums.length-1-i] = R[nums.length-i]*nums[nums.length-i];
        }

        for(int i=0;i<nums.length;i++){
            ans[i] = L[i]*R[i];
        }
        return ans;
    }
}
```

#### 解法2：优化空间复杂度为O(1)

**==状态压缩+空间复用

1. 状态压缩
当某个状态的计算只依赖于“相邻的前一个状态时”，就可以只需要用一个变量滚动更新即可
解法1中的R[]保存每个位置的右侧乘积
当前位置的右侧乘积**仅仅依赖于上一个位置的右侧乘积和上一个位置的元素值**

2. 空间复用
让结果数组ans在不同阶段扮演不同角色，既然最终总归要开辟一个结果数组，不如在计算的中间阶段，把它当成**中间状态**
在第一遍正向遍历时，`ans` 并不是最终结果，而是被当作了解法 1 中的 `L[]`（左侧前缀乘积）来使用。等到第二遍反向遍历时，再把动态计算的右侧乘积乘进去，完成“华丽转身”变成最终结果
```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int[] ans = new int[nums.length];
        ans[0] = 1;
        for(int i=1;i<nums.length;i++){
            ans[i] = ans[i-1]*nums[i-1];
        }
        int R=1;
        for(int i=nums.length-1;i>=0;i--){
            ans[i] = ans[i]*R;
            R *= nums[i];
        }
        return ans;
    }
}
```

# LeetCode 41. 缺失的第一个正整数

> 要求O(n)的时间复杂度，O(1)的空间复杂度

核心思想：原地哈希

关键发现：对于大小为N的数组，能装的下的正整数范围最多是（1，N），因此缺失的正整数范围一定在（1，N+1）内
空间复杂度要求为O(1)，就不能建立哈希表，**把数组本身当作哈希表用，建立索引和数值 的映射**，让数值X必须呆在X-1的位置上！（一个萝卜一个坑）

概括：
- 利用抽屉原理圈定范围，将原数组作为哈希表，让有效数字各就各位，最后巡视一遍，谁的坑被占了，缺的就是谁

```java

```
