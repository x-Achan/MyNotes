# LeetCode 3. 无重复字符的最长子串

#### 解法1：暴力

```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        if(s.isEmpty()) return 0;
        char[] chars = s.toCharArray();
        int ml = 1;
        for(int i = 0;i < chars.length;i++){
            HashSet<Character> set = new HashSet<>();
            int cl = 1;
            set.add(chars[i]);
            for(int j = i + 1;j < chars.length;j++){
                if(!set.contains(chars[j])){
                    set.add(chars[j]);
                    cl++;
                }else{
                    break;
                }
            }
            ml = Math.max(ml,cl);
        }
        return ml;
    }
}
```
##### 解法2：双指针维护滑动窗口

窗口类型：动态窗口
数据结构：用 HashSet 保存滑动窗口中的元素，用双指针维护窗口范围

==**用两个同样方向的指针维护一个动态区间，在满足条件时扩张，不满足条件时收缩，从而在一次遍历中找到最优解

暴力解法的缺点：abcd 是不重复的连续字符串，则 bcd 一定也是，所以每次换起点从前往后扫，大量的验证了已知的无重复区间

**关键：滑动窗口[right,left]无重复，则[right+1,left]一定无重复，所以right指针永远不需要回退


```java
class Solution {
    public int lengthOfLongestSubstring(String s) {
        HashSet<Character> set = new HashSet<>();
        int maxLen = 0;
        int right = 0;
        for(int i = 0;i < s.length();i++){
            if(i != 0)
                set.remove(s.charAt(i - 1));
            }
            while(right <= s.length() - 1 && !set.contains(s.charAt(right))){
                set.add(s.charAt(right));
                right++;
            }
            maxLen = Math.max(maxLen,set.size());
        }
        return maxLen;
    }
}
```

# ==LeetCode 239. 滑动窗口最大值==

#### 解法1：优先队列（堆）

数据结构：
- 二元组（值，索引），滑动窗口用索引来控制，判断当前的最大值是否在滑动窗口内
- 优先队列（大根堆）

PriorityQueue优先队列，默认小根堆
实现大根堆，需要重写Comparator比较器的compare(int a,int b)
 - compare 返回值 < 0 ，a排在b前面
 - > 0，b 排在 a 前面

大根堆降序排列的compare方法为：
```java
            public int compare(int[] pair1,int[] pair2){
                if(pair1[0] != pair2[0]){
                    return pair2[0] - pair1[0];
                }else{
                    return pair2[1] - pair1[1];
                }
            }
```

如果两个值相等，比较索引，索引大的排前面

常用方法：
- peek
- poll
- offer

滑动窗口向右移动，offer 新的元素，用大根堆提取最大值，判断最大值是否在滑动窗口内（滑动窗口的大小固定，用一个指针就可以确定范围）
如果最大值在滑动窗口范围内，就先不poll那些在滑动窗口范围外的元素
如果最大值peek不在滑动窗口范围内，将其从优先队列中移除，直到最大值的索引在滑动窗口内

**==关键理解：堆中保存的元素，不一定全都是滑动窗口的元素，只需要poll出滑动窗口外的的peek元素

#### ==解法2：单调队列(重要）==

单调队列：单调递减/递增的双端队列
Java中双端队列的实现，Deque接口有两种实现方法：LinkedList和ArrayList
常用方法：
- 入队：
	- offerLast()
	- offerFirst()
- 出队
	- pollLast()
	- pollFirst
- 队头队尾：
	- peekLast()
	- peekFirst()

**关键洞察：窗口向右移动，当nums[j] > nums[i]时，且j>i，则nums[i]永远不可能作为窗口的最大值**
1. **队首永远是当前窗口的最大值**
2. **新元素入队时，会踢掉所有比它小的元素**

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {
        Deque<Integer> dq = new LinkedList<>();
        int[] ans = new int[nums.length - k + 1]；
  
        for(int i=0;i<k;i++){
            while(!dq.isEmpty() && nums[dq.peekLast()] < nums[i]){
                dq.pollLast();
            }
            dq.offerLast(i);
        }
        ans[0] = nums[dq.peekFirst()];
        for(int i=k;i<nums.length;i++){
            while(!dq.isEmpty() && nums[dq.peekLast()] < nums[i]){
                dq.pollLast();
            }
            dq.offerLast(i);
            while(dq.peekFirst() <= i-k){
                dq.pollFirst();
            }
            ans[i-k+1] = nums[dq.peekFirst()];
        }
        return ans;
    }
}
```


# LeetCode 76. 最小覆盖子串

动态滑动窗口，用两个指针right和left维护

right 不断往右移动，直到窗口满足要求need

设计两个HashMap：need和window
need保存了t串中每个字符的出现次数，window中保存当前窗口的字符次数

如何判断window是否符合need的需求（window包含了need的所有字符）？
需要将把复杂的“包含所有字符”条件，抽象成简单的**整数比较**：
- 传统：双层遍历两个map，用equals比较（费时费力）
- 高级算法：用一个变量**valid记录状态**，表示了窗口window的合法性
每当window中新加的一个字符的数量达到need的要求，valid++
```java
if(window.get(C).equals(need.get(c))){
	valid++;
}
```
**当valid=need.szie()式，need中的所有字符都到达要求**

当left++，窗口缩小，也要判断是否需要valid--
need定需求，window定现状，valid判达标，达标就收缩，收缩记最短
