# LeetCode 104.二叉树的最大高度

推荐解法：
从下往上
返回高度信息
当前节点的最大高度 = max(左子树高度，右子树高度) + 1
从 null节点（0）开始累计高度，再到叶子节点（1），从下到上计算节点高度，传递到root

```java
class Solution {
    public int maxDepth(TreeNode root) {
        if(root == null) return 0;
        
        int leftmax = maxDepth(root.left);
        int rightmax = maxDepth(root.right);
        
        return Math.max(leftmax,rightmax) + 1;
    }
}
```

我的第一版解法：
从上到下传递 h，不断更新最大的 h
```java
class Solution {

    int maxDepth = 0;
    public int maxDepth(TreeNode root) {
        if(root == null) return 0;
        dfs(root,1);
        return maxDepth;

    }


    public void dfs(TreeNode root,int h){
        if(root == null) return;
        
        dfs(root.left,h+1);
        dfs(root.right,h+1);
        
        if(h>maxDepth){
            maxDepth = h;
        }
    }
}
```

# LeetCode 101.对称二叉树

- dfs()函数：判断两个树是否互为镜像
- 递归能力：

> 写递归的时候不能想着把每一层都展开
> 我已经定义好了dfs的功能，那么我直接相信dfs能帮我判断这两棵子树是否对称

例如：
```java
dfs(left.left, right.right)
```
不要继续想10层
只理解成：帮我判断两个外侧子树是否镜像

- 代码：
```java
class Solution {

    public boolean isSymmetric(TreeNode root) {

        if(root == null) return false;
        return dfs(root.left,root.right);

    }

    public boolean dfs(TreeNode left,TreeNode right){

        if(left == null && right == null){
            return true;
        }
        if(left == null || right == null){
            return false;
        }
        if(left.val != right.val){
            return false;
        }

        return dfs(left.left,right.right) && dfs(left.right,right.left);
    }

}
```

- 条件判断：
```java
        if(left == null && right == null){
            return true;
        }

        if(left == null || right == null){
            return false;
        }
```
理解：
第一个判断两个同时为null，返回true
第二个个判断至少有一个是null，返回false，由于第一个已经排除了两个同时为null的可能，所以其实第二个判断的是其中有一个是null的情况

从上到下的递归，判断节点和子树是否为镜像
先判断是否有节点为null的情况：left、right都为空/有一个为空
判断是否值不等，不等则结束递归，返回false
不需要判断相等的情况，因为值相等时，就自动递归到子树，判断子树的值
如果一直判断到树底为两个null，说明一直到树底都是镜像的，则返回true




# LeetCode 102.二叉树的层序遍历

关键是：返回二维数组
每一层要计算 q.size()，每一层有独立的list
```java
class Solution {

    public List<List<Integer>> levelOrder(TreeNode root) {

        List<List<Integer>> ans = new ArrayList<>();

        if(root == null) return ans;

        Queue<TreeNode> q = new LinkedList<>();
        q.offer(root);

        while(!q.isEmpty()){

            int size = q.size();
            List<Integer> list = new ArrayList<>(size);
            for(int i=0;i<size;i++){
                TreeNode removed = q.poll();
                list.add(removed.val);
                if(removed.left != null){
                    q.offer(removed.left);
                }
                if(removed.right != null){
                    q.offer(removed.right);
                }
            }
            ans.add(list);
        }
        return ans;
    }
}
```


# LeetCode 108.将有序数组转换为二叉树

数组 —> 二叉树

思路：递归 + 分治
二叉树最核心的递归思维：
当前节点做一件事 + 让左子树自己解决 + 让右子树自己解决

每个节点的最终创立都是当作root来创立的
递归的边界条件是当 left > right，此时数组索引范围内没有数据，则返回null
```java
class Solution {

    public TreeNode sortedArrayToBST(int[] nums) {
        return build(nums,0,nums.length-1);
    }

    public TreeNode build(int[] nums,int left,int right){
        if(left > right) return null;
        
        int mid = left + (right - left)/2;
        
        TreeNode root = new TreeNode(nums[mid]);
        
        root.left = build(nums,left,mid-1);
        root.right = build(nums,mid+1,right);

        return root;
    }
}
```


# LeetCode 98.验证二叉搜索树

递归思想不同于前面的区别
不同于简单的 dfs(root)
重点是，递归过程需要携带额外状态——带状态的递归
普通递归
```
只看当前节点
```
BST递归
```
当前节点需要满足祖先给的限制
```

从上往下携带状态

- 判断是否为二叉搜索树？
判断标准不是判断某个节点的左节点和右节点满足左节点小于当前节点，右节点大于当前节点，而是满足当前节点在某一个特定的时间区间内
即：
==判断以 root 为根节点的子树，是否满足二叉搜索树性质，并且当前节点必须处于合法范围 `(min, max)` 内。==

设计判断条件：BST合法情况太多，所以找违反条件的情况
当正确情况复杂，而错误情况简单时，优先设计错误条件

如果递归到空节点，说明一路上的节点都满足条件，返回 true

```java
class Solution {

    public boolean isValidBST(TreeNode root) {
        return dfs(root,Long.MIN_VALUE,Long.MAX_VALUE);
    }


    public boolean dfs(TreeNode root,long min,long max){
        if(root == null) return true;
        
        if(root.val >= max || root.val <= min){
            return false;
        }

        return dfs(root.left,min,root.val) && dfs(root.right,root.val,max);
    }
}
```

本道题的代码结构 和 LeetCode 101.对称二叉树相似
- 都是从上往下判断节点是否满足某种条件
- 合法条件判断都是：判断到null节点，说明一路上的节点都满足条件
区别在于，本题是带状态的递归

## LeetCode 105. 从先序和中序遍历数组构造二叉树

关键点：
- 跟114题二叉树展开为链表递归思想相似，**都是从叶子节点开始，递归处理左右子树，再向上传递，通过root做拼接**
- 在114的基础上，增加了98题验证二叉搜索树的**带状态的递归思想**
- 计算 root.right 和 root.left 的范围（leftSize是关键）

```java
class Solution {

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        return dfs(preorder,inorder,0,preorder.length-1,0,inorder.length-1);
    }

  
    public TreeNode dfs(int[] preorder,int[] inorder,int preBegin,int preEnd,int inBegin,int inEnd){
    
        if(preBegin > preEnd || inBegin > inEnd) return null;

        int rootVal = preorder[preBegin];
        TreeNode root = new TreeNode(rootVal);


        int index = inBegin;
        while(inorder[index] != preorder[preBegin]){
            index++;
        }

        int leftSize = index - inBegin;

  
        root.left = dfs(preorder,inorder,preBegin+1,preBegin+leftSize,inBegin,index-1);

        root.right = dfs(preorder,inorder,preBegin+1+leftSize,preEnd,index+1,inEnd);

  
        return root;

    }

}
```


## LeetCode 437 路径总和 Ⅲ

前缀和累加很可能超过 int 长度，所以需要使用 long 类型

```java
class Solution {

    int ans = 0;

        map.put(0L,1);
        dfs(root,0,targetSum);
        return ans;

        if(root == null) return;

        sum += root.val;
        
        ans += map.getOrDefault(sum - targetSum,0);
        
        map.put(sum,map.getOrDefault(sum,0)+1);

        dfs(root.left,sum,targetSum);
        dfs(root.right,sum,targetSum);
        
        map.put(sum,map.get(sum)-1);
    }
```

## LeetCode 236.二叉树最近的公共祖先（LCA）

不要从根节点向下找答案，而从让答案从底部返回

递归解法：叶子节点向上返回信息，当前节点利用信息解决问题（递归返回子树的信息，返回结果型递归）
- 二叉树最大深度：左右子树返回最大高度
- 是否平衡二叉树：返回当前节点是否满足范围
- 对称二叉树：返回是否镜像
- 返回从前序+中序构造二叉树：返回根据指定范围构造出来的树


本题：返回左右子树是否找到 p/q/null
当左右子树都返回节点时，说明当前节点就是最近的公共祖先

左右子树只有两种情况：
- 左右子树都找到
- 只有一个树找到
不存在都找不到的情况

递归的结束：当前节点为p/q/null（叶子节点）

```java
class Solution {

    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {

        // 递归终点
        // 判断节点是否为 p/q/null -> 返回root
        if(root == null || root == p || root == q){
            return root;
        }

        TreeNode left = lowestCommonAncestor(root.left,p,q);
        TreeNode right = lowestCommonAncestor(root.right,p,q);

        // 左右都有结果，p和q在两边，说明当前节点就是最近公共祖先
        if(left != null && right != null){
            return root;
        }
        return left != null ? left:right;
    }
}
```



# LeetCode 124.二叉树中最大路径和

本题的重点区分，答案值和返回值的重要区分！
- 答案值：当前节点作为最高点，是可以用到左右子树的信息
- 返回值：返回给父节点只能其中一边（最大的值）
返回值是更新全局变量条件

递归理解：
- 我的递归函数应该向上返回什么信息？
- 父节点如何利用这些信息？

类似于：二叉树的直径


```java
class Solution {

    int ans = Integer.MIN_VALUE;
    
    public int maxPathSum(TreeNode root) {
        dfs(root);
        return ans;
    }

    public int dfs(TreeNode root){
        if(root == null) return 0;
        
        int left = dfs(root.left);
        int right = dfs(root.right);


        int curVal = Math.max(left,0) + Math.max(right,0) + root.val;

        return Math.max(Math.max(left,0) + root.val,Math.max(right,0) + root.val);
    }

```

# LeetCode 543.二叉树的直径

>类似：124.二叉树中的最大路径和

遍历每个节点，算出每个节点的最大直径，然后更新最大直径（全局变量）

这道题是在二叉树的高度的基础上，增加了一个“更新全局变量”

dfs本质上就是在计算当前节点的最大高度Math.max(左子树最大高度,右子树最大高度) + 1

计算直径时，注意高度和边的关系，直径算的是边，左子树的高度 + 右子树的高度就是直径
**虽然二叉树的直径可能不经过root，但是最底下的叶子节点的直径，肯定会经过root**

所以通过 Math.max(左子树最大高度,右子树最大高度) + 1，从最底部一直计算上来，可以算出每个节点的直径，算出来后再和全局变量进行比较，更新最大值，最后返回

- 答案值：全局变量最大直径
- 返回值：左右子树最高高度 + 1
返回值是更新全局变量条件


```java
class Solution {

    int ans = 0;
    public int diameterOfBinaryTree(TreeNode root) {
        dfs(root);
        return ans;
    }

    public int dfs(TreeNode root){
        if(root == null) return 0;

        int leftmax = dfs(root.left);
        int rightmax = dfs(root.right);

        ans = Math.max(leftmax + rightmax,ans);
        return Math.max(leftmax,rightmax) + 1;
    }
}
```
