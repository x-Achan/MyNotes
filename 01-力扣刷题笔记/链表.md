# LeetCode 2. 两数相加

**两个链表的长度可能不一样长，当一个链表走到尽头时，p.val = 0**

用 carry 记录进位
- 进位的计算和每一轮的 sum 有关
- carry = sum / 10

当 p1 和 p2 都 == null 后，退出 while 循环
任然要判断一次 carry 的值是否 > 0，要将进位加到链表后

```java
class Solution {

    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode p1 = l1;
        ListNode p2 = l2;
        ListNode sumList = new ListNode(0);
        ListNode curr = sumList;
        int carry = 0;
        while(p1 != null || p2 != null){
            int num1 = (p1 == null)? 0 : p1.val;
            int num2 = (p2 == null)? 0 : p2.val;
            int sum = num1 + num2 + carry;
            carry = sum / 10;
            ListNode node = new ListNode(sum % 10);
            curr.next = node;
            curr = curr.next;
            
            if(p1 != null){
                p1 = p1.next;
            }
            if(p2 != null){
                p2 = p2.next;
            }
        }
        if(carry > 0){
            curr.next = new ListNode(carry);
        }
        return sumList.next;

    }

}
```

# LeetCode 19. 删除链表的倒数第 N 个节点

#### 解法1：求链表长度

**dummy哑节点：删除一个节点，需要用到其前驱节点，当删除节点为第一个节点是，由于没有头节点，就会产生特殊情况，，new 一个新的节点 dummy 用于删除头节点，统一首节点和中间节点的删除操作，最后返回 dummy.next。

```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        int length = 1;
        ListNode p = head;
        while(p.next != null){
            length++;
            p = p.next;
        }
        ListNode dummy = new ListNode(0,head);
        ListNode curr = dummy;
        for(int i = 1;i < length - n + 1;i++){
            curr = curr.next;
        }
        curr.next = curr.next.next;
        return dummy.next;
    }

}
```


#### 解法2：快慢指针法

让 fast 指针提前走 n 步，slow 呆在原地，fast 比 slow 快 n-1 个
fast 和 slow 同时往后移动，当 fast 移动到 最后一个节点（length），slow 指向的就是倒数第 n 个节点（length - n + 1）

两个指针从 dummy 开始，最后 slow 会指向被删除节点的前驱

```java
class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(0,head);
        ListNode fast = dummy;
        ListNode slow = dummy;

        for(int i=0;i<n;i++){
            fast = fast.next;
        }

        while(fast.next != null){
            fast = fast.next;
            slow = slow.next;
        }

        slow.next = slow.next.next;
        return dummy.next;
    }

}
```


# LeetCode 25. K个一组翻转列表

在 head 和 tail 内翻转链表的方法：
```java
private ListNode[] reverseList(ListNode head,ListNode tail){
        ListNode prev = tail.next;
        ListNode p = head;
        while(prev != tail){
            ListNode next = p.next;
            p.next = prev;
            prev = p;
            p = next;
        }
        return new ListNode[]{tail,head};
    }
```
**重点**：
- 传入 head 和 tail，返回一个二元组，刚好头尾互换
- while 循环的判断条件：prev 指向的是上一轮处理过的节点，当 prev == tail，代表最后一个节点 tail 已经处理过了，循环退出
- prev 初始化时要初始化为 tail.next

基础版 链表翻转：
```java

    }
```

# ==LeetCode 138. 随机链表的复制==

#### 深拷贝：建立“旧世界”到“新世界”的大门——哈希表

核心思想：以旧引新
将 oldNode 和 newNode 通过 map 链接起来，通过 map.get(oldNode) 可以找到 newNode

可以通过 map.get(oldNode.next) 找到旧链表的映射关系，新链表就可以复制旧链表的**拓扑结构（next 和 random）**

>错误做法：用哈希表存储 next 或者 random 的域关系，无法做到新旧链表的解耦

代码：
第一阶段：造肉体
第二节点：赋灵魂

``` java
class Solution {
    public Node copyRandomList(Node head) {
        Node curr = head;
        Map<Node,Node> map = new HashMap<>();
        while(curr != null){
            map.put(curr,new Node(curr.val));
            curr = curr.next;
        }
        curr = head;
        while(curr != null){
            map.get(curr).next = map.get(curr.next);
            map.get(curr).random = map.get(curr.random);
            curr = curr.next;
        }
        return map.get(head);
    }
}
```

核心1：建立新旧节点的映射
```java
Map<Node,Node> map = new HashMap<>();
```
核心2：新链表通过map找到旧链表的拓扑结构
```java
map.get(curr).next = map.get(curr.next);
map.get(curr).random = map.get(curr.random);
```

# LeetCode 148. 排序链表

#### 递归+归并

>归并：使用 21. 合并两个有序链表的做法

用快慢指针法找到链表的中点，然后切分为两个独立的链表 left 和 right，递归切分下去

快慢指针的初始化方法：
1. 创造 dummy，fast 和 slow 都从 dummy 出发，统一起点，逻辑整齐

```java
ListNode dummy = new ListNode(-1,head);
ListNode fast = dummy;
ListNode slow = dummy;

while(fast != null && fast.next != null){
	fast = fast.next.next;
	slow = slow.next;
}
```

2. slow 从 head 出发，fast 从 head.next 出发，本质就是 方法1的下一步
```java
ListNode fast = head.next;
ListNode slow = head;

while(fast != null && fast.next != null){
	fast = fast.next.next;
	slow = slow.next;
}
```

代码：
```java
class Solution {
    public ListNode sortList(ListNode head) {

        if(head == null || head.next == null){
            return head;
        }

        ListNode dummy = new ListNode(-1,head);
        ListNode fast = dummy;
        ListNode slow = dummy;


        while(fast != null && fast.next != null){
            fast = fast.next.next;
            slow = slow.next;
        }
        // 此处注意：需要将链表切分开
        ListNode mid = slow.next;
        slow.next = null;
        
        // 递归
        ListNode left = sortList(head);
        ListNode right = sortList(mid);

        return merge(left,right);

    }

    private ListNode merge(ListNode l1,ListNode l2){
        ListNode dummy = new ListNode(0);
        ListNode cur = dummy;

        while(l1 != null && l2 != null){
            if(l1.val >= l2.val){
                cur.next = l2;
                l2 = l2.next;
            }else{
                cur.next = l1;
                l1 = l1.next;
            }
            cur = cur.next;
        }

        if(l1 == null){
                cur.next = l2;
            }else{
                cur.next = l1;
            }
        return dummy.next;
    }
}
```


# LeetCode 23. 合并 K 个升序链表

1. 方法1：使用优先队列 PriorityQueue（小根堆）
```java
class Solution {

    public ListNode mergeKLists(ListNode[] lists) {
            PriorityQueue<ListNode> pq = new PriorityQueue<>((a,b) -> a.val - b.val);

            for(ListNode head : lists){
                if(head != null){
                    pq.offer(head);
                }
            }

            ListNode dummy = new ListNode(0);
            ListNode cur = dummy;

            while(!pq.isEmpty()){
                ListNode minNode = pq.poll();
                cur.next = minNode;
                cur = cur.next;
                
                if(minNode.next != null){
                    pq.offer(minNode.next);
                }
            }
            return dummy.next;
    }

}
```

2. 方法2：递归+分治

核心思想递归：每次将一个链表数组从中间分成两个部分，递归的将左右两部分合并成两个有序链表，再用合并两个有序链表的方法合并这两个结果

想象成拆分为了二叉树

**==核心操作：merge函数**==
==**负责把 [left,right] 区间内的链表合并成一条有序链表，并返回头节点==**

链表数组的长度不知道，先从中间一分为二，左右两边进行merge，返回合并好的有序链表
左右两边同时进行相同操作，一直递归下去
递归的终止条件是left == right

```java
class Solution {

    public ListNode mergeKLists(ListNode[] lists) {
        if(lists == null || lists.length == 0){
            return null;
        }
        return merge(lists,0,lists.length-1);
    }


    public ListNode merge(ListNode[] lists,int left,int right){
        if(left == right){
            return lists[left];
        }

        int mid = left + (right - left)/2;

		// 递归
        ListNode l1 = merge(lists,left,mid);
        ListNode l2 = merge(lists,mid+1,right);

        return mergeTwoLists(l1,l2);

    }

    public ListNode mergeTwoLists(ListNode l1,ListNode l2){

        ListNode dummy = new ListNode();
        ListNode cur = dummy;
        while(l1 != null && l2 != null){
            if(l1.val < l2.val){
                cur.next = l1;
                l1 = l1.next;
            }else{
                cur.next = l2;
                l2 = l2.next;
            }
            cur = cur.next;
        }

        if(l1 != null){
            cur.next = l1;
        }

        if(l2 != null){
            cur.next = l2;
        }
        return dummy.next;
    }

}
```

**==发现：==**
合并K个升序链表 & 排序链表 两道题的共同点
最终都是要得到一个升序链表
都是要递归到两个基本单位
然后调用merge
```java
// 递归到两个节点单位
ListNode left = sortList(head);
ListNode right = sortList(mid);

// 递归到两个链表单位
ListNode l1 = merge(lists,left,mid);
ListNode l2 = merge(lists,mid+1,right);
```

# LeetCode 146.LRU缓存（删除最久未使用，维护新旧顺序）
⭐⭐

题目的核心要求是：get 和 put 要做到 O(1) 的时间复杂度

1. 数据结构：HashMap + 双向链表
- 满足快速查找
- 满足快速调整顺序（最近使用的要放到第一个位置）
- Map用于快速查找，双向链表用于优先级排序

2. HashMap 负责定位，双向链表负责排序

3. HashMap存Node，而不是存 value

4. **==为什么不用单向链表？==**
- **单链表删除一个节点需要前驱，单链表无法直接得到前驱，需要遍历O(n)，双向链表可以通过prev指针找到前驱，原地完成删除操作！(O(1)的删除和移动)**

1. 虚拟头尾节点 head 和 tail，是为了避免大量的边界判断

```java
class LRUCache {

    class Node{
        int key;
        int value;
        Node prev;
        Node next;

        Node(){}
        Node(int key,int value){
            this.key = key;
            this.value = value;
            this.prev = null;
            this.next = null;
        }
    }

  

    // 维护一个哈希表
    Map<Integer,Node> map;
    //维护一个双向链表
    Node head;
    Node tail;

    int capacity;
    int size;

    public LRUCache(int capacity) {
        map = new HashMap<>();
        head = new Node();
        tail = new Node();
        head.next = tail;
        tail.prev = head;
        this.capacity = capacity;
        this.size = 0;
    }

    public int get(int key) {
        Node node = map.get(key);
        //key不存在
        if(node == null){
            return -1;
        }
        moveToHead(node);
        return node.value;
    }

    public void put(int key, int value) {
        Node node = map.get(key);
        if(node != null){
            node.value = value;
            moveToHead(node);
            return;
        }

        Node newNode = new Node(key,value);
        map.put(key,newNode);
        addToHead(newNode);
        size++;
        if(size > capacity){
            Node removed = removeTail();
            map.remove(removed.key);
            size--;
        }
    }


    public void addToHead(Node node){
        head.next.prev = node;
        node.next = head.next;
        node.prev = head;
        head.next = node;
    }

    public void removeNode(Node node){
        node.prev.next = node.next;
        node.next.prev = node.prev;
    }


    public void moveToHead(Node node){
        removeNode(node);
        addToHead(node);
    }


    public Node removeTail(){
        Node removed = tail.prev;
        tail = tail.prev;
        return removed;
    }

}

```

注意 
- LRUCache构造函数中，双链表初始化操作
```java
head.next = tail;
tail.prev = head;
```

- put操作中，如果node已经存在，要更新node的新value
- put操作中，超容量处理时，需要将最后一个node从链表和map中都删除（不能落下一个）
- 最后一个节点是 tail.prev 不是 tail，第一个节点是 head.next
