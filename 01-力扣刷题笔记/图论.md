
图的存储：邻接矩阵 vs 邻接表

### 1. 基础数据结构

- `ArrayList`：可以理解为**动态数组**，底层基于数组实现，可以自动扩容。
- `LinkedList`：基于**链表**实现，Java 中具体是双向链表。
- 普通数组 `int[]`：创建时长度固定，后续不能改变长度。

### 2. 邻接矩阵

使用二维数组：

```
int[][] graph = new int[n][n];
```

更适合：

> **稠密图：节点之间存在大量边。**

---

### 3. 邻接表

邻接表只保存**真正存在的边**。

Java 可以使用：

```
List<Integer>[] graph;
```

因此更适合：

> **稀疏图：边的数量远少于 V²。**

---

### 一句总结


> **邻接矩阵用 `int[][]` 为所有节点之间的关系预留空间，空间复杂度 O(V²)，适合稠密图；邻接表只保存实际存在的边，空间复杂度 O(V+E)，适合稀疏图。课程表中节点编号连续，但每个节点的出边数量不固定，因此使用 `List<Integer>[]`：数组下标表示节点，List 动态保存该节点的所有邻居。**

再压缩成一句口诀就是：

> **节点数量固定 → 外层数组；每个节点邻居数量不固定 → 内层 List。**


## LeetCode 200. 岛屿数量

本质：
>DFS求连通块数量

依次遍历每一个元素
如果是"1"，则进入dfs函数
dfs函数实现功能
>判断索引是否在范围内
>将当前元素置为0（标记为访问过，防止重复访问）
>递归调用dfs，对上下左右的元素都进行处理
>dfs(上)
>dfs(下)
>dfs(左)
>dfs(右)


```java
class Solution {
    public int numIslands(char[][] grid) {

        int ans = 0;
        for(int i = 0;i < grid.length;i++){
            for(int j = 0;j < grid[0].length;j++){
                if(grid[i][j] == '1'){
                    ans++;
                    dfs(grid,i,j);
                }
            }
        }
        return ans;
    }

    public void dfs(char[][] grid,int i,int j){

        if(i < 0 || i >= grid.length || 
        j < 0 || j >= grid[0].length || 
        grid[i][j] == '0'){
            return;
        }

        grid[i][j] = '0';
        
        dfs(grid,i-1,j);
        dfs(grid,i+1,j);
        dfs(grid,i,j+1);
        dfs(grid,i,j-1);
    }
}
```


## LeetCode 994. 腐烂的橘子

本质：
>多源BFS求扩散时间
>在二维网格中，多个起点同时向四周扩散，求扩散完成需要的最短时间

核心思想：
- BFS使用队列保存当前腐烂橘子
- Queue的每一层，代表同一时间腐烂的橘子
- 四个方向扩散，使用方向数组dirs，当前坐标 + 方向数组，实现四个方向的移动
- 感染逻辑：
	- 标记腐烂
	- fresh -1
	- 加入队列

```java
class Solution {

    public int orangesRotting(int[][] grid) {

        Queue<int[]> queue = new LinkedList();
        int fresh = 0;

		// 1.遍历所有点
        for(int i = 0; i < grid.length;i++){
            for(int j = 0; j < grid[0].length;j++){
	            // 1.2 将第一批腐烂的橘子加入队列
                if(grid[i][j] == 2){
                    queue.offer(new int[]{i,j});
                }
                // 1.3 统计好橘子的数量
                if(grid[i][j] == 1){
                    fresh++;
                }
            }
        }
        
        int[][] dirs = {
            {-1,0},
            {1,0},
            {0,1},
            {0,-1}};

        int time = 0;

        while(fresh > 0 && !queue.isEmpty()){
            int size = queue.size();
            time++;
            // 2.判断队列中的每一个烂橘子
            for(int i = 0;i < size;i++){
                int[] cur = queue.poll();
                // 3.找出烂橘子周围的好橘子，进行腐烂蔓延
                for(int[]dir : dirs){
                    int x = cur[0] + dir[0];
                    int y = cur[1] + dir[1];
                    if(x < 0 || x >= grid.length || y < 0 || y >= grid[0].length){
                        continue;
                    }
					// 腐烂蔓延，将蔓延的橘子重新加入队列
                    if(grid[x][y] == 1){
                        grid[x][y] = 2;
                        fresh--;
                        queue.offer(new int[]{x,y});
                    }
                }  
            }
        }
        // 判断是否全部腐烂
        return fresh==0 ? time:-1;
    }
}
```


## ==LeetCode 207.课程表==

本质：
>将课程关系建成有向图，然后对邻接表进行 DFS，判断有向图中是否存在环。

将题目给出的节点数量V和有向边存储E，转化为有向邻接表的形式
- 确定邻接表的数据结构
- 初始化邻接表

DFS判断是否有环
- 遍历List，从每一个节点出发，DFS相邻节点（有向）
- visted数组记录三状态，记录是否存在环：未访问/正在访问1/访问完成2
- 如果过程中访问到1，说明存在环

为什么外层还需要遍历所有节点numCourses？
>图不一定连通

```java
class Solution {

    List<Integer>[] graph;
    int[] viseted;

    public boolean canFinish(int numCourses, int[][] prerequisites) {

		// 1. 邻接表的初始化
        graph = new ArrayList[numCourses];
        
        for(int i =0;i < numCourses;i++){
            graph[i] = new ArrayList<>();
        }

        for(int[] e : prerequisites){
            int startV = e[1];
            int endV = e[0];
            graph[startV].add(endV);
        }
        
        // 2.访问状态数组
        viseted = new int[numCourses];

		// 3.深度遍历每一个节点
        for(int i = 0; i < numCourses;i++){

            if(!dfs(i)){
                return false;
            }
        }
        return true;
    }

  
    public boolean dfs(int i){

        if(viseted[i] == 1){
            return false;
        }
        if(viseted[i] == 2){
            return true;
        }

		// 1：正在遍历
        viseted[i] = 1;
        
        // 递归
        for(int next : graph[i]){
            if(!dfs(next)){
                return false;
            }
        }
        
        // 2：完成遍历
        viseted[i] = 2;
      
        return true;
    }

}
```

## LeetCode 208. 实现Trie（前缀树）

核心：
>利用树结构共享字符串公共前缀，`isEnd` 用来区分“前缀存在”和“完整单词存在”


1. 一个节点最多有 26 个孩子，每一个孩子本身又是一个 `Trie` 节点，因此这个孩子又拥有自己的Trie[26] childern
2. `isEnd` 表示“完整单词是否在这里结束”，路径存在是前缀存在，不等于单词存在
3. 字符通过 `c - 'a'` 映射成数组下标
4. `new Trie()` 创建的是一个新的前缀树节点，执行构造函数，并不是已经创建了 26 个子节点，只是**预留了 26 个引用位置**
5. 字符信息已经由“它在父节点 children 数组中的下标”表示


```java
class Trie {

    Trie[] children;
    boolean isEnd;
    
    public Trie() {
        this.children = new Trie[26];
        this.isEnd = false;
    }

// 插入
    public void insert(String word) {
        Trie currNode = this;
        for(char c : word.toCharArray()){
            int index = c - 'a';
            if(currNode.children[index] == null){
            // 只要构造了节点，就留下引用位置，表示当前存在字母，字母信息用下表表示
                currNode.children[index] = new Trie(); 
            }
            currNode = currNode.children[index];
        }
        currNode.isEnd = true;
        return;
    }
// 查找
    public boolean search(String word) {
        Trie currNode = this;
        for(char c : word.toCharArray()){
            int index = c - 'a';
            if(currNode.children[index] == null){
                return false;
            }
            currNode = currNode.children[index];
        }
        return currNode.isEnd;
    }

// 判断前缀
    public boolean startsWith(String prefix) {
        Trie currNode = this;
        for(char c : prefix.toCharArray()){
            int index = c - 'a';
            if(currNode.children[index] == null){
                return false;
            }
            currNode = currNode.children[index];
        }
        return true;
    }
}
```
