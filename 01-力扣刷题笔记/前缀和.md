# LeetCode 560. 和为 k 的子数组

##### 解法：前缀和 + 哈希表
将子数组问题转为差值问题

==前缀和的性质：==
**==子数组[i,j]的和 = [0,j]的前缀和 - [0,i-1]的前缀和
==**
要求子数组[i,j]的和为k
就是判断： 是否存在 [0,i-1]的前缀和 = [0,j]的前缀和 - k
- 存在，就是 找到字串和为 k
- 不存在，没有找到

数据结构：哈希表记录各个位置前缀和所出现的次数

用preSum计算每个位置的前缀和，并且保存到HashMap中
**用 HashMap 查找 当前前缀和 “preSum - k “ 这个值的子前缀和是否存在！

每一个子序列的前缀和，都是从第一个元素开始所计算的前缀和，减去某个子前缀和，得到k值！


3 4 7 ==2== -3 1 4 2；k=7

当指针指向 7 时：
判断子前缀和（3，7），能不能满足 ==当前前缀和（14） - 子前缀和（3/7） =  k（7）==
判断，当前前缀和减去某个子前缀和，能不能等于k值



## 模式 : “找搭档“思想核心框架
LeetCode 1. 两数之和，HashMap的解法，也用到本地的找搭档思想

==**找搭档思想核心框架：
- 列等式：将题目条件转换为数学关系，比如 a + b = sum，preSum[0,j] - preSum[0,i] = k
- 变形关系式：得到 partner = f(current,target)，在map里面找的搭档要满足的关系式
- 边走边存：当前元素既要找搭档，也可能成为后续元素的”潜在搭档“
	- 找搭档，HashMap找元素
	- 存入map，作为别人的搭档

==**Map的 value 存什么？
- 题目求什么，value存什么
	- 求索引，存下标
	- 求数量，存次数
	- 求所有组合，存List
