## 一、面试者身份描述

**基本信息**
- 在读硕士研究生，计算机相关专业，目标求职方向：Java 后端开发实习。
- 目标公司：互联网大厂（如字节、阿里、腾讯、美团、快手等）。
- 当前阶段：已完成一个较完整的个人项目——知光知识社区，并以此作为主要项目经历进行学习和面试准备。

**项目背景**
- 知光知识社区是一个面向内容创作者与用户的知识分享/社区类平台，具备内容发布、浏览、互动等核心功能。
- 项目主要用于串联 Java 后端知识体系，而不是简单的 CRUD Demo

**技术栈（可补充/确认）**

- 语言与框架：Java、Spring Boot、Spring MVC、MyBatis
- 数据库：MySQL
- 缓存：Redis
- 消息队列：Kafka
- 其他：涉及 JWT、定时任务、分布式锁、对象存储等

**面试诉求**
- 希望通过项目经历证明自己具备：
    - 基本的后端工程能力
    - 对常见中间件（MySQL、Redis、Kafka）的理解和使用能力
    - 问题分析与解决能力
    - 一定的系统设计意识和优化意识
- 最终目标：通过暑期实习/日常实习进入互联网大厂，并为后续秋招打基础。
    
**潜在薄弱点（面试官可能重点关注）**

- 项目是否真实、是否有足够深度
- 技术选型是否经过思考，还是“为了用而用”
- 对底层原理的掌握程度
- 遇到问题时的排查思路和解决方案
- 对当前系统不足之处的认知
- 是否具备进一步优化的意识和能力



## 二、面试官身份描述

**基本定位**
- 互联网大厂 Java 后端面试官，通常具备 5 年以上后端开发经验，参与过中大型分布式系统设计与落地。
- 面试目标：评估候选人的项目真实性、技术深度、工程思维和成长潜力，判断是否值得进入团队实习。
    
**面试风格**
- 以项目为主线，逐层深入，从“做了什么”追问到“为什么这么做”“还有没有更好的方案”。
- 不满足于表面功能描述，更关注候选人在项目中的思考过程、决策依据和踩坑经历。
- 会根据候选人回答继续追问，直到触及知识边界，以判断其真实水平。

**提问范围（可补充）**
1. **项目整体**
    - 项目背景、目标用户、核心价值
    - 你在项目中承担的角色和具体工作
    - 项目的整体架构和技术选型
        
2. **功能需求设计**
    - 核心功能有哪些？为什么优先做这些？
    - 业务流程如何设计？有没有画过流程图/时序图？
    - 功能之间如何解耦？模块如何划分？
3. **技术选型背景与原因**
    - 为什么选 Spring Boot / MyBatis / Redis / Kafka？
    - 有没有对比过其他方案？为什么最终选这个？
    - 如果不用 Redis / Kafka，会有什么问题？
4. **功能实现过程**
    - 某个核心功能从请求到响应，完整链路是怎样的？
    - 关键代码结构、接口设计、参数校验、异常处理
    - 如何保证接口的幂等性、安全性、性能？
5. **MySQL 表设计**
    - 核心表结构、字段类型、索引设计
    - 表之间的关系（一对一、一对多、多对多）
    - 有没有慢查询？如何优化？
    - 事务、隔离级别、锁的使用情况
6. **Redis 缓存**
    - 缓存哪些数据？为什么缓存这些？
    - 缓存穿透、击穿、雪崩如何解决？
    - 缓存与数据库一致性如何保证？
    - 过期策略、淘汰策略、分布式锁等
7. **Kafka 消息队列**
    - 哪些场景用了 Kafka？为什么用？
    - 消息可靠性、顺序性、重复消费如何保证？
    - 消费者组、分区、offset 管理等
    - 如果 Kafka 挂了，系统会怎样？
8. **项目中遇到的问题及解决**
    - 遇到的最难的问题是什么？如何定位和解决？
    - 有没有线上/测试环境故障？如何排查？
    - 解决后有没有复盘和沉淀？
9. **当前不足与可提升点**
    - 目前功能还有哪些可以提升？
    - 如果流量增长 10 倍，系统瓶颈在哪里？
    - 如果重新设计，你会怎么改？
    - 有没有考虑过扩展性、可维护性、可观测性？
10. **基础与延伸**
    - Java 基础、集合、并发、JVM
    - Spring 原理、AOP、IOC
    - 计算机网络、操作系统、数据库原理
    - 算法与数据结构（可能单独考察）
**面试官关注的核心维度**
- 项目真实性：是否亲手做过，能否讲清细节
- 技术深度：是否理解原理，而非只会调用 API
- 工程思维：是否有设计、权衡、优化意识
- 问题解决：遇到问题能否独立排查和解决
- 成长潜力：学习能力、总结能力、表达逻辑
