完整事件投入流程：
```
Kafka 消费到"帖子事件"
    ↓
FeedProjectionService.projectPost(event)
    ↓
① 查 MySQL：findById(event.postId())
    ↓
② 分类：
    ├─ "不存在 / deleted" → "清理"
    └─ "存在" → "更新"
    ↓
③ "公开+已发布" → "加热门"
    ↓
④ "大V / 普通" → "拉/推"
    ↓
⑤ 完成 ✅
```


和其他服务的关系

帖子事件 PostProjectionEvent 有两种类型：UPSERT 和 DELETE
```java
public record PostProjectionEvent(  
        String eventId,  
        long postId,  
        String op,  
        long ts  
) {  
  
    public static final String UPSERT = "UPSERT";  
    public static final String DELETE = "DELETE";  
  
    public static PostProjectionEvent upsert(long postId) {  
        return new PostProjectionEvent(  
                UUID.randomUUID().toString(),  
                postId,  
                UPSERT,  
                System.currentTimeMillis()  
        );  
    }  
  
    public static PostProjectionEvent delete(long postId) {  
        return new PostProjectionEvent(  
                UUID.randomUUID().toString(),  
                postId,  
                DELETE,  
                System.currentTimeMillis()  
        );  
    }  
}
```

## 收到事件的处理

先查帖子
```java
KnowPost post = knowPostMapper.findById(event.postId());
```

##### 如果帖子已经删除或不存在
```java
if (post == null || "deleted".equals(post.getStatus()))
```

清理所有索引和缓存
```java
// 1.从主页Feed删
feedIndexService.removeAuthorPost(post);
// 2.1 关注Feed删：大v版本 + 1，页面缓存失效
feedIndexService.bumpBigVEpoch();
// 2.2 关注Feed删：普通粉丝inbox删
feedIndexService.projectOrdinaryPost(post, false);
// 3.热门Feed删
feedIndexService.removeHotCandidate(event.postId());

// 4.删帖子分片缓存
feedCacheService.evictPost(event.postId());
```

##### 帖子存在

更新作者Feed，刷新帖子分片缓存
```java
feedIndexService.upsertAuthorPost(post);  
feedCacheService.refreshPost(post.getId());
```

###### 公开+已发布，则加入热门候选，否则从热门候选中移除

```java
boolean publicPublished =
        "published".equals(post.getStatus())
        && "public".equals(post.getVisible());

if (publicPublished) {
    feedIndexService.addHotCandidate(post);
} else {
    feedIndexService.removeHotCandidate(post.getId());
}
```

###### 是大V还是普通

```java

// ① 大V → "加入 BIG_AUTHORS" + "版本 +1"
redis.opsForSet().add(
					FeedKeys.BIG_AUTHORS, 
					String.valueOf(post.getCreatorId()));
					feedIndexService.bumpBigVEpoch();

// ② 普通 → "推送给粉丝"
feedIndexService.projectOrdinaryPost(post, followingEligible);
```
