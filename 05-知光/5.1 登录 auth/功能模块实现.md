
# 一、账号标准化

登录功能、注册功能、修改密码
都需要传入帐号类型和账号
```
IdentifierType identifierType
String identifier
```
账号类型有两个：电话、邮箱
```java
public enum IdentifierType {  
    PHONE,  
    EMAIL;
}
```
需要对账号进行格式验证和标准化处理
```java
// 把用户输入的账号"清洗"成标准格式，再拿去查库或存储  
private String normalizeIdentifier(IdentifierType type, String identifier) {  
    return switch (type) {  
        case PHONE -> identifier.trim();  
        case EMAIL -> identifier.trim().toLowerCase(Locale.ROOT);  
    };  
}  
  
// 手机号/邮箱格式验证  
private void validateIdentifier(IdentifierType type, String identifier) {  
    if (type == IdentifierType.PHONE && !IdentifierValidator.isValidPhone(identifier)) {  
        throw new RuntimeException("手机号格式错误");  
    }  
    if (type == IdentifierType.EMAIL && !IdentifierValidator.isValidEmail(identifier)) {  
        throw new RuntimeException("邮箱格式错误");  
    }  
}
```

# 二、登录 login

1. 登录请求：
- 账号类型
- 账号
- 验证码
- 密码
```java
public record LoginRequest(  
        @NotNull(message = "账号类型不能为空") IdentifierType identifierType,  
        @NotBlank(message = "账号不能为空") String identifier,  
        String code,  
        String password  
) {  
}
```

2. 过程

账号格式验证和标准化处理
```java
validateIdentifier(request.identifierType(), request.identifier());  
// 1. 标准化账号  
String identifier=normalizeIdentifier(
									request.identifierType(),
									request.identifier());
```
查询用户是否存在
```java
Optional<User> userOptional = findUserByIdentifier(
										request.identifierType(),
										identifier);
// 判断用户是否存在  
if (userOptional.isEmpty()) throw new RuntimeException("账号不存在");  
User user = userOptional.get();
```
这个findUserByIdentifier是根据账号类型，进行数据库查询
```java
// 根据账号类型（手机/邮箱），调用不同的 Service 方法去数据库查用户  
private Optional<User> findUserByIdentifier(IdentifierType type, String identifier) {  
    return switch (type) {  
        case PHONE -> userService.findByPhone(identifier);  
        case EMAIL -> userService.findByEmail(identifier);  
    };  
}
```

如果用户输入了密码password，优先用密码登录，校验密码
```java
passwordEncoder.matches(request.password(), user.getPasswordHash())
```
没有输入密码，但输入了验证码code，校验验证码
```java
verificationService.verify(VerificationScene.LOGIN, identifier, request.code());
```
登陆成功，生成Access Token 和 Refresh Token，Refresh Token 保存到Redis中
```java
// 生成TokenPair  
TokenPair tokenPair = jwtService.issueTokenPair(user);  
// 将 refrshToekn存储到redis中  
refreshTokenStore.storeToken(user.getId(), tokenPair.refreshTokenId(), ttl);
```
返回：用户信息 & TokenPair信息

# 三、注册 register

1. 请求
- 账号类型
- 账号
- 验证码
- 密码
- 服务条款同意
```java
public record RegisterRequest(  
        @NotNull(message = "账号类型不能为空") IdentifierType identifierType,  
        @NotBlank(message = "账号不能为空") String identifier,  
        @NotBlank(message = "验证码不能为空") String code,  
        String password,  
        boolean agreeTerms  
) {  
}
```

2. 过程
判断服务条款是否同意 agreeTerms = true
账号格式验证和标准化处理
```java
validateIdentifier(request.identifierType(), request.identifier());  
// 1. 标准化账号  
String identifier=normalizeIdentifier(
									request.identifierType(),
									request.identifier());
```
判断账号是否存在
```java
boolean isExist = identifierExists(request.identifierType(), identifier);
```
identifierExists根据账号查询数据库
```java
// 验证手机号/邮箱已经存在  
private boolean identifierExists(IdentifierType type, String identifier) {  
    return switch (type) {  
        case PHONE -> userService.existsByPhone(identifier);  
        case EMAIL -> userService.existsByEmail(identifier);  
    };  
}
```
验证码校验，注册必须使用验证码注册
```java
verificationService.verify(VerificationScene.REGISTER, identifier, request.code())
```
验证成功，创建用户对象，保存到数据库中
```java
// 创建一个新的用户  
User user = User.builder()  
        .phone(request.identifierType() == IdentifierType.PHONE ? identifier : null)  
        .email(request.identifierType() == IdentifierType.EMAIL ? identifier : null)  
        .nickname(generateNickname())  
        .avatar("https://static.zhiguang.cn/default-avatar.png")  
        .bio(null)  
        .tagsJson("[]")  
        .build();  
// 如果输入密码，添加到user属性中  
if (StringUtils.hasText(request.password())) {  
    // 密码格式验证  
    //validatePassword(request.password());  
    // 对密码进行hash编码，然后存入user属性中  
    user.setPasswordHash(passwordEncoder.encode(request.password().trim()));  
}  
  
// insert user,添加到数据库后，user才会有userId  
User userStored = userService.createUser(user);
```
注册即登录，生成 TokenPair
```java
// 注册即登录，生成tokenPair,将refreshtoken存入redis中  
TokenPair tokenPair = jwtService.issueTokenPair(userStored);  
refreshTokenStore.storeToken(userStored.getId(), tokenPair.refreshTokenId(), ttl);
```
返回：用户信息 & TokenPair信息


# 三、退出登录 logout

1. 请求
- refreshToken 刷新令牌
```java
public record LogoutRequest(  
        @NotBlank(message = "刷新令牌不能为空")  
        String refreshToken) {  
}
```

2. 过程

解析令牌信息，得到Jwt
```java
Jwt jwt = jwtService.decode(freshToken);
```
获取 Claims：令牌类型、用户id、令牌id
```java
String tokenType = jwtService.extractTokenType(jwt);  
long userId = jwtService.extractUserId(jwt);  
String tokenId = jwtService.extractTokenId(jwt);
```
令牌类型如果是 refresh token，则在redis中删除对应的key
key
```
`auth:rt:{userId}:{tokenId}
```
删除后，标识该刷新令牌失效
```java 
redisTemplate.delete(keys);  
```
登出返回 `ResponseEntity.noContent().build()`,它返回一个 HTTP 204 No Content 响应，表示"操作成功，但响应体为空"

# 四、修改密码

1. 请求
- 账号类型
- 账号
- 验证码
- 新密码
```java
public record PasswordResetRequest(  
        @NotNull(message = "账号类型不能为空") IdentifierType identifierType,  
        @NotBlank(message = "账号不能为空") String identifier,  
        @NotBlank(message = "验证码不能为空") String code,  
        @NotBlank(message = "新密码不能为空") String newPassword  
) {  
}
```

2. 过程

账号格式验证和标准化处理
```java
validateIdentifier(request.identifierType(), request.identifier());  
// 1. 标准化账号  
String identifier=normalizeIdentifier(
									request.identifierType(),
									request.identifier());
```
密码验证格式验证
```java
validatePassword(request.newPassword());
```
查询用户是否存在，验证码校验，更新数据库，刷新refreshToken
```java
// 2.数据库用户是否存在，取出用户对象  
User user = findUserByIdentifier(request.identifierType(), identifier)  
        .orElseThrow(() -> new RuntimeException("用户不存在"));  
// 3.验证码校验  
ensureVerificationSuccess(verificationService.verify(VerificationScene.RESET_PASSWORD, identifier, request.code()));  
// 4.存入新的密码  
user.setPasswordHash(passwordEncoder.encode(request.newPassword().trim()));  
userService.updatePassword(user);  
// 5.刷新refreshToken,登出所有设备
refreshTokenStore.revokeAll(user.getId());
```

返回 `ResponseEntity<Void>`
