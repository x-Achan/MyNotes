## 1.1 验证码生成

验证码生成用 `SecureRandom` 而非 `Random`，防止攻击者预测
```java
private static final SecureRandom RANDOM = new SecureRandom();
```

| 随机数                | 用途               |
| ------------------ | ---------------- |
| **`Random`**       | 普通（伪随机，可预测）      |
| **`SecureRandom`** | **安全用途（验证码、密钥）** |
字符串拼接
```java
private static String generateNumericCode(int length) {  
    StringBuilder builder = new StringBuilder(length);  
    for (int i = 0; i < length; i++) {  
        builder.append(RANDOM.nextInt(10));  
    }  
    return builder.toString();  
}
```

## 1.2 验证码存储

>存储验证码到Redis

存储三种信息：
- 验证码 code
- 发送间隔限制标识 
- 每日发送次数限制 limit

| Key                                   | 存的         | 用途         |
| ------------------------------------- | ---------- | ---------- |
| `auth:code:{scene}:{id}`              | 验证码 + 尝试次数 | **验证码校验**  |
| `auth:code:last:{scene}:{id}`         | 发送标记（"1"）  | **发送间隔限流** |
| `auth:code:count:{scene}:{id}:{date}` | 计数器        | **日限额**    |

>三者配合，形成完整的防刷体系

1. 存储code data
key标识使用场景和账号（邮箱/验证码）
```
key: auth:code:{sence}:{identifier}
```
Vaule采用Hash结构，有三个字段
```
value：
	code:
	maxAttempts:
	attempts:
```
Java代码：
```java
// 保存验证码到 Redis Hash，并设置 TTL
HashOperations<String, String, String> ops = redisTemplate.opsForHash();
ops.put(key, FIELD_CODE, code);  
ops.put(key, FIELD_MAX_ATTEMPTS, String.valueOf(maxAttempts));  
ops.put(key, FIELD_ATTEMPTS, "0");  
redisTemplate.expire(key, ttl);
```

2. 重发时间间隔标识

key
```
auth:code:last:{sence}:{identfier}
```
key
```java
String key = "auth:code:last:" + scene.name() + ":" + identifier;
```

value值（类似Refresh Token）
```
1
```

TTL设置为时间间隔，比如60s
```java
String existing = stringRedisTemplate.opsForValue().get(key);  

if (existing != null) {  
    throw new RuntimeException("请60秒后重试");  
}
stringRedisTemplate.opsForValue().set(key, "1", interval);
```

每次插入标识前都要判断标识是否存在，如果存在说明TTL没有过期，重发时间还没到
如果不存在，才重新存储标识

3. 每日重发上限
key
```
auth:code:count:{scene}:{identifier}:{date};
```
key
```java
String key = "auth:code:count:" + scene.name() + ":" + identifier + ":" + date;
```
value值
```
每日上限具体次数
```
自增添加值
```java
Long count = stringRedisTemplate.opsForValue().increment(key);
```
自增后需要判断value是否超过上限 limit
```java
if (count != null && count > limit) {  
    throw new RuntimeException("超过每日上限");  
}
```

# 二、验证码校验

有了场景sence 和 identifier，拼接为key，从Redis中取出数据(Map)
```java
HashOperations<String, String, String> ops = redisTemplate.opsForHash();  
// 1.取出redis中的data  
Map<String, String> data = ops.entries(key);
```
解析内容：code、attempts、maxAttempts
```java
String storedCode = data.get(code);  
int maxAttempts = data.get(maxAttempts);
int attempts = data.get(attempts);
```

验证码校验：Redis中存储的 code 和用户请求发来的 code是否相同
相同则删除Redis记录
```java
if (Objects.equals(storedCode, code)) {  
    redisTemplate.delete(key);  
    return;  
}
```
不同则校验失败，将尝试次数 attempts + 1并保存到Redis中
```java
int updatedAttempts = attempts + 1;  
ops.put(key, FIELD_ATTEMPTS, String.valueOf(updatedAttempts));
```
