
# 数据库（真相源）


```sql
CREATE TABLE like_record (
  id         BIGINT UNSIGNED NOT NULL AUTO_INCREMENT,
  user_id    BIGINT UNSIGNED NOT NULL,
  post_id    BIGINT UNSIGNED NOT NULL,
  type       VARCHAR(16) NOT NULL COMMENT 'like / fav',
  created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (id),
  UNIQUE KEY uk_user_post_type (user_id, post_id, type),   -- ★ 幂等的唯一保障
  KEY ix_post_type (post_id, type),                        -- 支撑 COUNT(*) 与对账
  KEY ix_user_type_created (user_id, type, created_at)     -- ★ 支撑"我的点赞列表"
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

# Redis key 清单
| key                                     | 类型         | 用途        | 结构说明                                           |
| --------------------------------------- | ---------- | --------- | ---------------------------------------------- |
| `bitmap:{etype}:{eid}:{metric}:{chunk}` | String(位图) | 谁赞过（事实热态） | 例 `bitmap:knowpost:367228634206965760:like:27` |
| `cnt:{etype}:{eid}:{metric}`            | String     | 有多少赞（派生）  | 例 `cnt:knowpost:367228634206965760:like`       |
| `cnt:index`                             | Set        | 对账抽样索引    | 成员 `{postId}:{metric}`，如 `367...:like`         |
| `lock:counter-reconcile`                | —          | 对账分布式锁    | Redisson 管理                                    |
