桶里面存令牌，操作拿到令牌才可以执行
- 桶容量capacity
- 补充速率rate

## 1. 令牌桶实现：Redis + Lua

以限制用户关注速度为例（防止操作太频繁）
关注令牌桶，限制只能突发关注 100 次，则桶的容量为100

Key
```
rl:follow:{userId}
```

==**value：hash**==
```
rl:follow:{userId} = {
    last: 1716192000,      # 上次填充时间（秒）
    tokens: 100            # 当前令牌数
}
```

Lua脚本：保证"读 + 补 + 消耗"原子
脚本核心语句
计算token
```lua
local elapsed = tonumber(now) - tonumber(last)  
tokens = math.min(capacity, tonumber(tokens) + elapsed * rate)
```
token不够
```lua
if tokens < 1 then  
    redis.call('HSET', key, 'last', now)    
    redis.call('HSET', key, 'tokens', tokens)    
    redis.call('EXPIRE', key, 60)    
    return 0
end
```
token够，消耗一个令牌，返回1代表成功
```lua
tokens = tokens - 1  
redis.call('HSET', key, 'last', now)  
redis.call('HSET', key, 'tokens', tokens)  
redis.call('EXPIRE', key, 60)  
return 1
```
为用户获取一个令牌函数，脚本返回1且不为null，代表获取成功
```java
public boolean tryAcquire(long userId) {  
    Long r = redis.execute(  
            ACQUIRE,  
            List.of(RelationKeys.followRateLimit(userId)),  
            String.valueOf(capacity),  
            String.valueOf(rate));  
    return r != null && r == 1L;  
}
```


令牌桶的时间用 redis.call('TIME')， 而不是 Java 传，因为每台服务器的now不一样
