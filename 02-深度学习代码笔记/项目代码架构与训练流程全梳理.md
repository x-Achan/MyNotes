## 1. 项目总览与核心思想

**VideoMamba-DINO** 是一个用于 **无人机视频目标检测** 的深度学习框架，核心思想是：

- **VideoMamba**：用 Mamba（状态空间模型 SSM）替代 Transformer 做视频时序建模，提取视频帧序列的时空特征。相比 Transformer 的 O(N²) 注意力，Mamba 只有 O(N) 复杂度，更适合长视频序列。
- **DINO**：基于 DETR 的端到端检测框架，使用可变形注意力（Deformable Attention）+ 对比去噪训练（Contrastive Denoising），无需 NMS 后处理即可直接输出检测结果。
- **融合创新**：VideoMamba 提取视频 token → 多层聚合 → SFP 构建多尺度特征 → 时序融合注入邻帧信息 → DINO 检测头输出检测结果。

**任务**：给定一段连续 8 帧的 UAV 无人机视频，检测中间帧中的车辆目标（car、truck、bus、vehicle 共 4 类）。

### 5.2 UAVDTDataset 类详解

```python
class UAVDTDataset(Dataset):
    def __init__(self, root, split, num_frames=8, frame_interval=1,
                 sliding_step=None, img_size=(640, 1088)):
```

**核心流程**：

1. **`_build_sample_list()`**：扫描 `img/` 目录，按序列名（`_img` 前缀）分组，用滑动窗口切分出固定长度（`num_frames` 帧）的视频片段。

   - `frame_interval=1`：帧间隔，取连续帧
   - `sliding_step=1`：滑动步长，步长越小采样密度越大
   - `span = (num_frames - 1) * frame_interval + 1`：每个片段覆盖的帧跨度

2. **`__getitem__(idx)`**：
   - 加载 8 帧图像
   - 加载**中间帧**（第 4 帧，索引=8//2=4）的标注作为检测目标
   - 调用 `_transform_clip()` 做数据增强
   - 返回 `(images, target)`，其中 `images` 形状为 `[C, T, H, W]`，`target` 是字典

3. **`_transform_clip()`**：对整个片段做一致性增强（关键！不同帧必须做同样的空间变换，否则时序建模会被破坏）：
   - 所有帧 resize 到 `(640, 1088)`
   - 训练时：随机亮度/对比度/饱和度（同一值应用于所有帧）、随机水平翻转（同步翻转录的框坐标）、10% 概率高斯模糊
   - ImageNet 标准化：`mean=[0.485, 0.456, 0.406]`, `std=[0.229, 0.224, 0.225]`

4. **`_load_annotations()`**：从 JSON 标注文件解析框坐标，转为归一化的 `cxcywh` 格式：
   - 过滤超出画面边界的物体（`_is_out_of_frame()`）
   - 归一化：`cx = (x1+x2)/(2*img_w)`，`bw = (x2-x1)/img_w`

### 5.3 返回的数据格式

```python
# images: [C, T, H, W] = [3, 8, 640, 1088]
# target: dict
{
    'labels':    Tensor[N],      # 类别标签（0-3）
    'boxes':     Tensor[N, 4],   # 归一化 cxcywh 格式
    'image_id':  Tensor[1],      # 图像 ID（用于 mAP 计算）
    'orig_size': Tensor[2],      # 原始图像 [H, W]
}
```

### 5.4 collate_fn

`build_uavdt_collate_fn()`：简单的堆叠函数，`images` 用 `torch.stack` 拼成 `[B, C, T, H, W]`，`targets` 保持为 list（因为每张图的检测目标数不同）。

### 6.1 VideoMamba 骨干网络

**文件**：`models/videomamba.py`

**核心组件**：VisionMamba 类，24 层 BiMamba Block。

#### PatchEmbed — 视频分块嵌入

```python
class PatchEmbed(nn.Module):
    def __init__(self, img_size=224, patch_size=16, kernel_size=1,
                 in_chans=3, embed_dim=192):
        self.proj = nn.Conv3d(
            in_chans, embed_dim,
            kernel_size=(kernel_size, patch_size, patch_size),
            stride=(kernel_size, patch_size, patch_size)
        )
```

- 使用 **3D 卷积**将视频切分为 patch（tubelet embedding）
- `kernel_size=1`：时间维度不做压缩（每帧独立分块）
- `patch_size=16`：空间上 16×16 像素为一个 patch
- 输入 `[B, 3, T, H, W]` → 输出 `[B, 192, T, H/16, W/16]`

#### Block — Mamba 块

```python
class Block(nn.Module):
    # Pre-norm 架构: Add → LayerNorm → Mamba Mixer
    def forward(self, hidden_states, residual, ...):
        residual = residual + drop_path(hidden_states)
        hidden_states = self.norm(residual)
        hidden_states = self.mixer(hidden_states)  # BiMamba
        return hidden_states, residual
```

- 使用 **残差连接**（类似 ResNet）
- `mixer` 是双向 Mamba（BiMamba），通过 `mamba_ssm` 库实现
- Mamba 本质是**状态空间模型 (SSM)**：用隐状态 `h(t) = Ah(t-1) + Bx(t)` 建模序列，比 Transformer 的自注意力更高效

#### VisionMamba.forward_features() — 特征提取主流程

```python
def forward_features(self, x):  # x: [B, C, T, H, W]
    # 1. Patch embedding
    x = self.patch_embed(x)          # [B, 192, T, H_p, W_p]

    # 2. 展平空间维度并添加位置编码
    x = x.permute(0,2,3,4,1).reshape(B*T, H_p*W_p, 192)  # [B*T, N, C]
    x = cat(cls_token, x) + pos_embed                          # 加空间位置编码

    # 3. 添加时间位置编码（关键！让模型区分不同帧）
    x = rearrange(x, '(b t) n m -> (b n) t m', b=B, t=T)
    x = x + temporal_pos_embedding   # [B*N, T, C] 加时间位置编码
    x = rearrange(x, '(b n) t m -> b (t n) m', b=B, t=T)

    # 4. 通过24层 Mamba Block，在指定层提取特征
    for idx, layer in enumerate(self.layers):
        hidden_states, residual = layer(hidden_states, residual)
        if idx in self.out_indices:  # [5, 11, 17, 23]
            feat = hidden_states[:, 1:, :]  # 去掉 cls token
            feat = feat.reshape(B, T, -1, C).reshape(B*T, -1, C)
            features[idx] = feat

    return features  # dict{5: [B*T, N, 192], 11: ..., 17: ..., 23: ...}
```

**关键设计**：
- **时空联合建模**：Mamba 序列长度 = `T × N`（时间×空间），模型在一个序列中同时处理时空信息
- **多层输出**：4 个不同深度的层输出特征，浅层捕获细节，深层捕获语义
- **去掉 cls token**：检测任务需要所有空间位置的特征，不需要全局特征

#### videomamba_tiny() — 构建函数

```python
def videomamba_tiny(pretrained=False, pretrained_path=None, out_indices=None, **kwargs):
    model = VisionMamba(
        patch_size=16, embed_dim=192, depth=24,
        rms_norm=True, bimamba=True,  # 双向Mamba
        out_indices=out_indices, **kwargs
    )
```

- 参数量约 **7M**（非常轻量）
- 预训练权重来自 **Kinetics-400** 视频分类数据集

### 6.2 多层特征聚合器

**文件**：`models/feature_aggregator.py`

**问题**：VideoMamba 是非层级结构（所有层输出相同空间分辨率），4 层特征维度相同但语义深度不同。

**解决方案**：`MultiLayerFeatureAggregator` 学习一个加权组合：

```python
class MultiLayerFeatureAggregator(nn.Module):
    def __init__(self, dim=192, num_layers=4):
        self.proj = nn.ModuleList(
            [nn.Sequential(nn.LayerNorm(dim), nn.Linear(dim, dim)) for _ in range(num_layers)]
        )
        self.layer_weights = nn.Parameter(torch.zeros(num_layers))  # 可学习权重

    def forward(self, features):  # dict{layer_idx: [B*T, N, 192]}
        weights = F.softmax(self.layer_weights, dim=0)  # 归一化权重
        out = sum(proj(feat) * weight for weight, proj, (_, feat) in ...)
        return out  # [B*T, N, 192]
```

- 每层先 LayerNorm + Linear 投影，再加权求和
- 权重通过 softmax 归一化，初始化为等权

### 6.3 简单特征金字塔 SFP

**文件**：`models/sfp.py`

**问题**：VideoMamba 只输出单一尺度特征（stride=1/16），DINO 检测头需要多尺度特征。

**解决方案**：参考 ViTDet 的 Simple Feature Pyramid，用反卷积上采样 + 步进卷积下采样构建 4 个尺度：

```
输入: [B*T, 192, H/16, W/16]    (backbone_dim=192)
  │
  ├── lateral_conv (1×1 Conv) ──→ [B*T, 256, H/16, W/16]  ← Level 1 (stride 1/16)
  │                               │
  │   ┌── up_block ──────────────→ [B*T, 256, H/8, W/8]   ← Level 0 (stride 1/8)
  │   │  (ConvTranspose2d 2×)
  │   │  + Conv2d 3×3
  │   │
  │   ├── down_block[0] ────────→ [B*T, 256, H/32, W/32]  ← Level 2 (stride 1/32)
  │   │  (Conv2d stride=2 × 2层)
  │   │
  │   └── down_block[1] ────────→ [B*T, 256, H/64, W/64]  ← Level 3 (stride 1/64)
  │      (Conv2d stride=2 × 2层)
  │
  输出: 4个特征图, 通道数均为 256
```

**对于 UAVDT (640×1088)**：

### 6.4 时序融合模块

**文件**：`models/temporal_fusion.py`

**问题**：DINO 检测头只对**中心帧**做监督，但多帧特征如何聚合？

**方案一：mean（基线）**—— 直接取 T 帧均值，无参数。

**方案二：conv1d**—— 深度可分离 1D 时间卷积，沿时间维度融合。

**方案三：recalib（当前使用，推荐）**—— SE 门控重校准：

```python
class TemporalRecalibFusion(nn.Module):
    def forward(self, x):  # x: [B, T, C, H, W]
        center = x[:, T//2]  # 中心帧特征

        # 1. 时间卷积融合邻帧信息
        y = temporal_conv(x)  # → [B, C, H, W]

        # 2. 计算门控信号
        temporal_var = x.var(dim=1)  # 时间维度方差
        stats = cat([center.mean(dim=(2,3)), temporal_var.mean(dim=(2,3))])  # [B, 2C]
        gate = sigmoid(MLP(stats))  # [B, C, 1, 1]

        # 3. 门控融合
        out = y * gate + center * (1 - gate)  # 自适应选择信任时序融合还是中心帧

        return norm(out)  # [B, C, H, W]
```

**核心思想**：当相机运动导致帧间差异大时（UAV 场景常见），门控倾向于保留中心帧特征；当帧间变化平稳时，门控倾向于使用时序融合信息。

### 6.6 可变形 Transformer

**文件**：`models/deformable_transformer.py`

这是 DINO 的核心，包含 3 个子模块：

#### DeformableTransformer（主类）

```python
class DeformableTransformer(nn.Module):
    def forward(self, srcs, masks, refpoint_embed, pos_embeds, tgt, attn_mask):
        # 1. 展平多尺度特征 + 添加 level embedding
        src_flatten = cat([src.flatten(2) for src in srcs])
        lvl_pos_embed_flatten = cat([pos + level_embed[lvl] for ...])

        # 2. Encoder 编码
        memory = self.encoder(src_flatten, pos, ...)

        # 3. Two-Stage 提案生成（关键！）
        output_memory, output_proposals = gen_encoder_output_proposals(memory, ...)
        # 用 enc_out_class_embed 对每个位置打分，选 Top-K=300 个作为初始框
        topk_proposals = torch.topk(class_scores.max(-1), 300)
        refpoint_embed = gather(enc_outputs_coord, topk_proposals)

        # 4. Decoder 解码
        hs, references = self.decoder(tgt, memory, ...)

        return hs, references, hs_enc, ref_enc, init_box_proposal
```

#### TransformerEncoder（6层）

每层是 `DeformableTransformerEncoderLayer`：
- **多尺度可变形自注意力**（MSDeformAttn）：每个参考点只关注附近少量采样点，而非全局注意力
- **FFN**：两层 Linear + ReLU

#### TransformerDecoder（6层）

每层是 `DeformableTransformerDecoderLayer`，按 `['sa', 'ca', 'ffn']` 顺序执行：
1. **sa**：标准多头自注意力（query 之间交互）
2. **ca**：可变形交叉注意力（query 从编码器 memory 中提取信息）
3. **ffn**：前馈网络

**迭代精修机制**（关键！）：
```python
# 每一层 decoder 都精修一次 bbox
for layer_id, layer in enumerate(self.layers):
    output = layer(output, ...)                    # 解码层前向
    delta = self.bbox_embed[layer_id](output)      # 预测残差
    new_ref = (delta + inverse_sigmoid(ref)).sigmoid()  # 残差加到参考框上
    reference_points = new_ref.detach()            # 下一层的参考框
```

### 6.7 去噪训练组件 DN

**文件**：`models/dn_components.py`

DINO 的核心创新之一——**对比去噪训练 (Contrastive Denoising)**：

**目的**：加速训练收敛。将 GT 框加噪声后作为额外的 query 送入 Transformer，让模型学会去噪还原。

```python
def prepare_for_cdn(dn_args, training, ...):
    # 1. 复制 GT 标签和框
    known_labels = labels.repeat(2 * dn_number)  # 正+负两组
    known_bboxs = boxes.repeat(2 * dn_number)

    # 2. 给标签加噪声（随机替换类别）
    if label_noise_ratio > 0:
        p < 0.5 * label_noise_ratio → 替换为随机类别

    # 3. 给框加噪声（随机偏移坐标）
    if box_noise_scale > 0:
        known_bbox_ += rand_part * diff * box_noise_scale

    # 4. 构建 attention mask：DN query 之间不能互相看到
    attn_mask[pad_size:, :pad_size] = True  # object queries 不能看 DN
    # 不同 DN 组之间也不能互相看
```

**对比去噪**：正噪声（小偏移）和负噪声（大偏移）同时训练，让模型学会区分"这是同一个物体"还是"这是不同物体"。

### 6.8 检测头 (分类+回归)

位于 `VideoMambaDINO.__init__()` 中：

```python
# 分类头：每个 decoder 层各一个
```

### 6.9 VideoMambaDINO 主模型

**文件**：`models/videomamba_dino.py`

`VideoMambaDINO.forward()` 是整个前向传播的入口：

```python
def forward(self, samples, targets=None):  # samples: [B, C, T, H, W]
    # 1. 预处理：5D视频 → 展平为 4D 图像
    B, C, T, H, W = samples.shape
    flat_samples = samples.permute(0,2,1,3,4).flatten(0,1)  # [B*T, C, H, W]

    # 2. 骨干网络提取特征
    backbone_features = self.backbone(video_samples)  # dict{layer_idx: [B*T, N, 192]}

    # 3. 多层特征聚合
    backbone_feature = self.feature_aggregator(backbone_features)  # [B*T, N, 192]

    # 4. SFP 构建多尺度金字塔
    fpn_features = self.sfp(backbone_feature, img_size=(H, W))  # 4个 [B*T, 256, h_i, w_i]

    # 5. 通道投影 + 位置编码
    for level, feat in enumerate(fpn_features):
        srcs.append(self.input_proj[level](src))  # 192→256 或保持256

    # 6. 时序融合 [B*T, C, h, w] → [B, C, h, w]
    for level in range(len(srcs)):
        src_t = srcs[level].view(B, T, C, h, w)
        srcs[level] = self.temporal_fusion[level](src_t)  # → [B, C, h, w]
        masks[level] = masks[level].view(B, T, h, w)[:, T//2]  # 取中心帧 mask
        poss[level] = poss[level].view(B, T, C, h, w)[:, T//2]  # 取中心帧 pos

    # 7. 准备 DN 去噪 query
    input_query_label, input_query_bbox, attn_mask, dn_meta = prepare_for_cdn(...)

    # 8. Transformer 编码+解码
    hs, reference, hs_enc, ref_enc, init_box_proposal = self.transformer(
        srcs, masks, input_query_bbox, poss, input_query_label, attn_mask
    )

    # 9. 检测头预测
    for layer_ref_sig, layer_bbox_embed, layer_hs in zip(reference[:-1], self.bbox_embed, hs):
        layer_delta_unsig = layer_bbox_embed(layer_hs)         # MLP 预测残差
        layer_outputs_unsig = layer_delta_unsig + inverse_sigmoid(layer_ref_sig)  # 加到参考框
        outputs_coord_list.append(layer_outputs_unsig.sigmoid())  # sigmoid 归一化

    outputs_class = [layer_cls_embed(layer_hs) for ...]  # 分类 logits

    # 10. 分离 DN query 和 object query
    outputs_class, outputs_coord_list = dn_post_process(...)

    return {
        'pred_logits': outputs_class[-1],   # [B, 300, 4] 最后一层分类
        'pred_boxes': outputs_coord_list[-1], # [B, 300, 4] 最后一层框
        'aux_outputs': [...],                # 中间层辅助输出
        'dn_meta': ...                        # DN 去噪信息
    }
```

## 7. 损失函数与匹配器

### 7.1 匈牙利匹配器

**文件**：`models/matcher.py`

**目的**：将模型的 300 个预测与 GT 框进行最优一对一匹配。

**算法**：匈牙利算法（`scipy.optimize.linear_sum_assignment`），解决二部图最优匹配。

**代价矩阵**：
```python
C = cost_class * focal_class_cost + cost_bbox * L1_cost + cost_giou * GIoU_cost
# cost_class=2.0, cost_bbox=8.0, cost_giou=2.0
```

- **Focal 分类代价**：基于 sigmoid 概率的 focal loss 形式
- **L1 回归代价**：预测框与 GT 框的 L1 距离
- **GIoU 代价**：广义 IoU 的负值（IoU 越大代价越小）

**输出**：每个图像返回 `(pred_indices, gt_indices)` 的配对。

### 7.2 SetCriterion 损失计算

**文件**：`models/criterion.py`

#### 三类损失

| 损失 | 公式 | 权重 |
|------|------|------|
| **分类损失** `loss_ce` | Focal Loss (sigmoid, α=0.25, γ=2) | 2.0 |
| **回归损失** `loss_bbox` | L1 Loss（匹配对之间） | 8.0 |
| **GIoU 损失** `loss_giou` | 1 - GIoU（匹配对之间） | 2.0 |

#### 损失计算流程

```python
def forward(self, outputs, targets):
    # 1. 匈牙利匹配
    indices = self.matcher(outputs_without_aux, targets)

    # 2. 归一化因子 = 所有图像 GT 框总数 / GPU 数
    num_boxes = sum(len(t["labels"]) for t in targets) / world_size

    # 3. 主输出损失
    for loss in ['labels', 'boxes', 'cardinality']:
        losses.update(self.get_loss(loss, outputs, targets, indices, num_boxes))

    # 4. 辅助损失（每个 decoder 中间层都算一次）
    for i, aux_outputs in enumerate(outputs['aux_outputs']):
        aux_indices = self.matcher(aux_outputs, targets)  # 重新匹配
        losses.update(loss_on(aux_outputs, aux_indices, suffix=f'_{i}'))

    # 5. 编码器中间输出损失
    if 'interm_outputs' in outputs:
        losses.update(loss_on(interm_outputs, suffix='_interm'))

    # 6. 编码器输出损失
    if 'enc_outputs' in outputs:
        for i, enc_out in enumerate(outputs['enc_outputs']):
            losses.update(loss_on(enc_out, suffix=f'_enc_{i}'))

    # 7. DN 去噪损失
    if dn_meta:
        losses.update(loss_on(dn_outputs, suffix='_dn'))

    return losses
```

**总损失**：
```python
losses = sum(loss_dict[k] * weight_dict[k] for k in loss_dict if k in weight_dict)
```

```python
def train_one_epoch(model, criterion, train_loader, optimizer, epoch, cfg, device):
    model.train()
    criterion.train()
    scaler = torch.cuda.amp.GradScaler()  # 混合精度训练

    for samples, targets in train_loader:
        samples = samples.to(device)   # [B, C, T, H, W]
        targets = [{k: v.to(device) for k, v in t.items()} for t in targets]

        optimizer.zero_grad()

        # 混合精度前向
        with torch.cuda.amp.autocast():
            outputs = model(samples, targets)  # 前向传播
            loss_dict = criterion(outputs, targets)  # 计算损失
            losses = sum(loss_dict[k] * weight_dict[k] for k in loss_dict if k in weight_dict)

        # 反向传播 + 梯度裁剪 + 更新
        scaler.scale(losses).backward()
        scaler.unscale_(optimizer)
        torch.nn.utils.clip_grad_norm_(model.parameters(), clip_max_norm=0.1)
        scaler.step(optimizer)
        scaler.update()

        # 日志记录
        metric_logger.update(loss=losses_reduced_scaled, **clean_log_dict)
```

**关键技术**：
- **混合精度训练**（AMP）：用 FP16 前向/反向，FP16 梯度缩放，节省显存加速训练
- **梯度裁剪**：`clip_max_norm=0.1`，防止梯度爆炸
- **日志清洗**：过滤掉辅助层和 DN 的损失，只记录主损失

```python
class PostProcess:
    def forward(self, outputs, target_sizes, nms_iou_threshold=0.5, num_select=300, conf_threshold=0.0):
        # 1. Sigmoid 得到分类概率
        prob = out_logits.sigmoid()

        topk_values, topk_indexes = torch.topk(prob.view(B, -1), num_select)

        for cls in labels.unique():
```

```
      │
      ▼ SimpleFeaturePyramid.forward()
  [[B*T,256,80,136], [B*T,256,40,68], [B*T,256,20,34], [B*T,256,10,17]]
      │
      ▼ input_proj (Conv2d 1×1 + GroupNorm)
  [[B*T,256,80,136], [B*T,256,40,68], [B*T,256,20,34], [B*T,256,10,17]]
      │
      ▼ reshape to [B, T, C, h, w] → Temporal Fusion
  [[B,256,80,136], [B,256,40,68], [B,256,20,34], [B,256,10,17]]
      │
      ▼ Position Encoding
  srcs + masks + poss (每个都是4个尺度的列表)
      │
      ▼ prepare_for_cdn() (训练时)
  input_query_label, input_query_bbox, attn_mask, dn_meta
      │
      ▼ DeformableTransformer.forward()
  ┌─ Encoder: 多尺度可变形自注意力 → memory [B, Σ(h*w), 256]
  ├─ Two-Stage: Top-300 proposals → refpoint_embed [B, 300, 4]
  └─ Decoder: 6层迭代精修
       hs: [6, B, 300, 256]  (每层decoder的输出)
       references: [7, B, 300, 4]  (参考框)
      │
      ▼ 检测头
  class_embed(hs) → pred_logits [B, 300, 4]
  bbox_embed(hs) + reference → pred_boxes [B, 300, 4] (cxcywh)
      │
      ▼ dn_post_process() (训练时)
  分离 DN query 和 object query 的输出

损失计算:
  HungarianMatcher → 匹配预测与GT
  SetCriterion → focal_loss + L1_loss + GIoU_loss × 所有decoder层 + DN损失
```

### 14.3 低mAP根因分析

**1. 严重过拟合** — train loss 12.89→2.65, val loss 56→106
- loss_ce降到0.004, 训练集几乎完美分类但无法泛化
- weight_decay=0.0001远低DINO标准0.001; drop_path_rate=0.1偏低
- 数据增强太弱(无RandomCrop/ScaleJitter/Mosaic)

**2. 时序建模严重不足** — 整条链路最薄弱环节
- SSM 192-dim hidden state编码21760个token, 时序信息被稀释
- Temporal Fusion仅0.06M参数/4组, SE-gated conv1d无力建模复杂时序
- Feature Aggregator和SFP完全无视时序维度

**3. 伪多尺度** — 4层输出同分辨率, SFP人工构造的金字塔缺乏真正多尺度感受野

**4. num_queries配置矛盾** — yaml设100但two_stage用Top-300

**5. mAP_large不稳定** — 从0.0853到0.1740波动, 时序一致性建模失败

### 14.4 改进方向 (详见 架构总结与时序策略创新.md)

**主线**: 运动引导的时序选择性扫描 + 运动引导时序特征聚合
**辅线**: 分层时序建模、双向时序解耦、时序Query传播
**快速收益**: 修训练策略(num_queries/weight_decay/drop_path/数据增强)
